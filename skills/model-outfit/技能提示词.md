# 模特换装

状态：应用技能设计初稿；商品组和本项目标图由后端分别绑定并标注角色。

## prompt.main

将当前模特参考图中的指定服装替换为用户商品。商品图只代表同一款商品，不将不同角度当成不同款式。

当前参考：{{target.label}}；替换对象：{{target.description}}。
换装模式：{{fields.replacementMode}}。
补充要求：{{user.requirements}}。
新宣传文案：{{fields.newCopy}}。
本图变体：{{item.variant}}。

整件换装时，新商品的领型、版型、袖长、衣长、口袋、印花、Logo、颜色与可见材质纹理以商品参考为准，不继承旧衣服结构。只换图案或颜色时，保留原服装版型和褶皱关系，仅替换明确指定的元素。

保持指定人物身份、面部、体型、姿态、背景和镜头关系；其他人物与非目标服装不修改。结合真实遮挡与人体结构表现穿着，避免肢体变形和图案漂移。新品与原姿态冲突时做必要且克制的穿着调整，不虚构背面结构。

去除旧广告文案、价格、旧品牌及促销标记，商品本体印字以用户新品为准。未提供新文案则不新增文字。一次只输出当前目标的一张成品。
