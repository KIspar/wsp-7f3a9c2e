# 一键对标

状态：Q5–Q7 已确认：白底独立按钮；替换可提前排队等待所选白底；每图 item 可编辑，未提交可保存，已提交修改用于新尝试；白底失败等待用户处理。图片全局默认 20 并发，可配置。元数据为待实现协议，不能直接运行。

## prompt.white-background

仅依据本次自有商品图，为同一件商品制作一张完整的商品白底资料图。背景为干净纯白、不透明，清晰表现商品已知轮廓，保留领型、袖长、衣长、缝线、口袋、颜色、印花、Logo 和可见文字。

去掉原场景与干扰物，不保留人物或人体局部，不添加包装、道具、宣传文案、价格和水印。不猜测商品背面与原图不可见的结构。不要将重绘的缺失细节当作准确实物。商品资料是否充分由用户在提交前确认或补图，首版不声称已有自动视觉预检。

用户补充：{{user.requirements}}。

## prompt.replace

当前对标图片：{{target.label}}；需要替换的对象：{{target.description}}。
换装范围：{{fields.replacementMode}}；本图变体：{{item.variant}}。
新宣传文案：{{fields.newCopy}}。
用户补充：{{user.requirements}}。

参考包含用户自有商品原图组与本次已勾选的当前对标图；仅在用户选择白底模式时额外提供白底参考。原始商品图是款式真值，白底图存在时仅作辅助，不得因白底重绘误差改变实际商品。

保留对标图的人物身份、姿态、场景、机位和可适配光线，将指定服装替换成自有商品。整件换装以新品版型、领口、袖长、口袋和印花为准；只换图案或颜色时保留旧版型。不得改变未指定人物或其他商品。

服装自然贴合人体，保持真实遮挡和合理褶皱；不沿用旧衣服的品牌或图案，不虚构新品未知背面。移除旧宣传文案、价格、促销和旧广告品牌；新文案为空时不新增广告文字。新品本体 Logo 和印字准确保留。

每次只输出当前目标的一张独立图片，不拼接本批其他参考图，不把多个任务的结果串联生成。
