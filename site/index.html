A FEW THINGS TO KNOW

还有一点想了解？

需要自己安装 Node.js 或其他运行环境吗？+

不需要。上方完整包已包含工作台核心运行环境，完整解压后双击启动文件即可。环境缺失时，启动器会从 GitHub 自动下载并校验。可选本地视频工具的状态，可在工作台帮助页查看。

启动失败，或者 Mac 提示无法打开怎么办？+

先关闭正在运行的工作台，再双击 Windows-修复环境.bat 或 Mac-修复环境.command。修复保留本机作品、数据和 API 配置；重新下载环境时需要联网。Mac 如果丢失执行权限，可使用 Mac-修复权限.command；来源确认请按 macOS 的右键“打开”及系统提示操作。

免费下载后，可以直接使用所有模型吗？+

工作台免费下载。调用在线模型需要在模型配置中添加你自己的中转站 API Key，模型费用由对应服务商收取。你可以选择模型与分组，并在工作台中查看相关配置。

我的素材和 API Key 保存在什么地方？+

素材、数据库和凭据保存在本机的 data 文件夹，不随程序发布到 GitHub。调用在线模型时，生成所需的相关输入会发送到你配置的服务商。请妥善保管本机文件，并定期备份。

以后如何更新？旧版本的数据怎么办？+

工作台支持从公开 GitHub Release 检查并后台下载更新。你确认安装后，程序先保存、检查任务并备份，再重启；启动失败会尝试恢复。如果从旧文件夹手动迁移，请先关闭旧程序并备份 data，不要让两个程序同时使用同一份数据。
