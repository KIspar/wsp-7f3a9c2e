GET STARTED

首次使用，三步就绪。

  1. 01

    准备运行环境

    安装 Node.js 24 或更新版本。

    下载 Node.js ↗
  2. 02

    下载并解压

    将上方程序包解压到固定文件夹，
    在该文件夹打开终端。

    请先解压，再运行
  3. 03

    启动工作台

    依次执行以下命令，打开启动器显示的本机地址。

    npm ci --omit=dev
    npm start
↻

后续更新，在工作台完成。

默认自动检查 GitHub 新版本并后台下载。在版本面板安装后，程序会备份、重启；启动失败时恢复旧版。首次安装完成后，日常只需运行 npm start，并保留启动窗口。
