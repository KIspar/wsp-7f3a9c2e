第一次使用，需要自己安装环境吗？+

不需要。上方完整包已包含适合本机的运行环境。完整解压后双击启动文件即可。轻量包或环境缺失时，启动器会从 GitHub 自动下载并校验；使用期间请保留启动窗口。

启动失败了，怎么修复？+

先关闭正在运行的工作台，再双击 Windows-修复环境.bat 或 Mac-修复环境.command。修复会重新准备运行环境，保留你的作品、数据和 API 配置。Mac 如提示启动文件没有执行权限，可使用 Mac-修复权限.command；系统来源确认请按 macOS 的“右键 → 打开”提示操作。

已经下载过旧包，还需要重新下载吗？+

如果文件夹里没有这些启动入口，请下载新版 ZIP 并完整解压。已有数据先关闭旧程序并单独备份 data 文件夹，或使用工作台的备份功能。
