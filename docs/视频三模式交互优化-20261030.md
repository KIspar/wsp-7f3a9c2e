# 商品工坊：视频三模式交互优化

日期：2026-10-30。范围：商品工坊推广制作中的视频界面，沿用现有主题、中文字体和共享基础控件。手机端适配按此前约定暂不纳入。

## 交互调整

三种制作方式统一放到工作区顶部，切换时可以直接理解各自用途；图文仍可从“切换图文”进入。

| 方式 | 主要输入 | 页面重点 |
|---|---|---|
| 直接生成 | 商品图片、视频创作要求 | 保留左侧作品任务列表；右侧直接创作，分镜脚本按需展开 |
| 参考视频反推 | 同行视频、商品图、调整要求、改写脚本 | 同行视频放在前面，用户主动反推后检查脚本；反推与生成分开执行 |
| 爆款逐帧复刻 | 原片、商品图、镜头要求、确认首帧、选用片段、音轨 | 独立分镜制作工作区，按阶段处理，不沿用普通长表单 |

生成模型、比例、时长及模型参数直接显示在创作栏中。视频发布文案从脚本区进入，移除底部重复入口。右侧创作栏沿用 1280／1440／1920px 下 480／520／560px 的宽度。

## 逐帧复刻工作区

- **分镜反推**：展示镜头证据、语音、分析记录、商品替换与分镜提示词；镜头范围调整只在此阶段出现。
- **商品首帧**：编辑重绘与替换要求，查看首帧候选，确认用于视频生成的首帧。
- **分镜视频**：展示已确认首帧、动作提示词、按秒计费时长和视频候选。
- **合成成片**：中央播放器预览候选成片；右侧集中显示片段采用情况、音轨及合成操作。

镜头条横向排列；中央只对照当前镜头的原首帧、已确认商品首帧和已选片段。阶段与右侧字段同步，切换阶段不卸载镜头字段状态。任务选择在本机保存，再次进入可恢复任务。

结果保持候选状态，只有明确确认才进入作品版本。生成、采用、合成及下载继续使用原有业务接口与计费规则。本轮 UI 验收未发起新的付费分析或媒体生成，也未确认已有成片。

## 控件与动效

任务操作复用共享 Popover 和浮层协调机制；参数复用自定义 Select，无原生下拉。Esc 关闭后焦点返回入口。阶段切换使用既有动效令牌，悬停以颜色变化为主，支持减少动态效果。

分镜候选与成片播放器默认暂停，避免切换阶段自动播放声音；其余现有播放器保持原先默认行为。预览区固定比例，媒体加载不改变工作区外框。
