# 爆款逐帧复刻：实施记录与验收边界

更新：2026-10-30。本次是现有商品工坊扩展，保留 Node 后端与 React、TypeScript、Vite、shadcn 自定义控件。充值后已完成本轮真实GK视频生成、原音轨合成与导出验收；独立同行素材效果、无开发环境Windows及完整兼容矩阵验收仍未完成。

## 已实现

入口：商品工坊 → 商品 → 推广制作 → 视频 → 爆款逐帧复刻。

- 左侧任务及分镜对照，右侧独立创作栏；直接生成、参考反推、分镜复刻各自保存草稿。
- 本地 Python 固定命令执行，claude-real-video 0.10.7、PySceneDetect 0.6.7.1、faster-whisper 1.2.1、FFmpeg；CPU int8、中文、离线 Whisper base。Python 不持有供应商密钥。
- 检查真实视频流与 MP4/WebM 格式、30MB/120秒；保存关键帧、场景、三张镜头证据帧、带时间戳转写与原音轨。重复场景保留不同时间位置，连续范围不遗漏；切点可拆分、合并、裁切，单镜头不超过15秒，总片段不超过20。
- 主动调用辅助模型反推，结构化字段可编辑。每镜头输入三张时序帧和一张商品图，明确采样局限。迟到结果不能覆盖已修改字段，应用结果不可重复；镜头文字与切点在本机保留。
- 首帧重绘使用独立真实图片模型。原视频首帧为编辑底图，商品图提供外观；分析图号转换为素材语义，防止分析顺序与重绘顺序混淆。
- 每镜头独立报价、提交、候选采用；GK 固定单张首帧、1–15秒整数、480p/720p。小数时长向上取整计费，保留时长独立显示。
- 复用 Batch/Attempt 和真实媒体队列，CreativeContext 记录任务、镜头、阶段、内容修订。旧报价或旧内容候选被拦截，已提交快照不被后续修改。
- 接单和每次媒体调度重新查余额，考虑未结算本地保留金额。分析也执行计费线路、余额预检查，按token预估而非固定价。提交未知不自动重发，已知任务号继续查询结果与最终费用。
- 本地合成选定片段，按源时间轴统一尺寸、30fps、H.264/AAC、硬切；丢弃生成片段音轨，原音轨按范围截取；替换音轨裁尾或补静音，支持静音。
- 成片候选保存分镜与音轨快照，确认后成为独立推广作品版本。支持同款／跨商品复刻新任务；跨商品清除商品事实与原提示词，要求重新反推／填写。复刻不自动调用付费接口。
- ZIP 导出 MP4、分镜 JSON、提示词 Markdown、转写及版本信息。普通备份包含本地拆解产物，私有密钥目录继续排除。
