## 界面与采用验收

- 填写隔离商品售价和卖点，自动保存；刷新后仍保留。
- 主图、详情、SKU、图文和视频草稿分别存储，切换不会覆盖普通技能草稿。
- 主图候选完成时不进入商品预览；点击采用后才增加已采用位置。
- 详情候选按屏采用；两页图文分别采用后按页出现在推广预览。
- 真实视频采用后在推广预览可打开自定义播放器。
- 下拉打开后只有一个 listbox、一个 expanded trigger；Escape 关闭正常。
- 素材选择弹窗可查看原图；放大前后图片弹窗外框保持 1140×844.8px，缩放比例从 45% 到 56%，支持既有滚轮/拖拽机制与按钮/键盘操作。
- 已采用素材支持拖拽及上移/下移；浏览器操作验证主图排序改变并持久化。
- 从推广切回产品编辑，右侧正确回到商品详情。
- 修复 SKU 采用时保留旧颜色位置 ID 导致校验拒绝的问题，使用任务快照目标 ID 替换绑定。
- 图片预览与视频控件复用系统组件，手机预览不使用原生视频 controls。

## 明确边界

首版采集只承诺已验证的军埔公开结构与已配置资源域名。遇到站点结构变化、登录验证码、防盗链或新资源域名时保留部分结果并提示人工补充；没有浏览器自动绕过或任意站点采集。

媒体真实适配目前为配置中的 TT Image 2.5、Omni Flash。新增模型需要先验证输入、参数、返回结构与费用，不能只修改名称就宣称接入。

首版无抖店发布、库存/订单/支付、自由图层、多段剪辑或配音字幕轨道。生成效果仍需用户审阅；“参考人物”不等于模型能绝对保持同一人。

116 项自动化使用隔离数据和明确测试替身，不等于 116 次真实付费调用；生产验收的真实记录仅为上表七个供应商任务。
