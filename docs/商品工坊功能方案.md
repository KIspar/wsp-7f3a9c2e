# 商品工坊：链接采集与商品内容制作

本规范对应已实现的首版，采用 React + TypeScript + Vite、shadcn/ui、Fastify、SQLite 与本地素材存储。入口 `/catalog`，商品编辑 `/catalog/:id`。

## 定位与核心流程

以一款商品组织资料、素材、制作、候选版本与交付：

**粘贴链接 → 后台采集 → 商品入库 → 编辑资料 → 查询报价 → 真实生成 → 采用候选 → 预览与下载。**

保留现有图片、视频与分析技能。商品工坊新增商品层，复用技能、报价、余额、凭据及任务查询服务。

首版不做抖店发布、订单、库存同步、真实支付、自由图层设计或多段自动剪辑。手机外框是桌面上的商品效果模拟器。

## 页面与交互

| 页面 | 已实现内容 |
|---|---|
| 商品库 | 紧凑表格、链接采集、搜索、采集状态、素材数量、分页、重采、归档与恢复，右侧选择预览 |
| 商品编辑 | 左侧按用途编辑，右侧固定手机外框，独立滚动，可收起预览 |
| 商品任务与素材 | 编辑页“任务”入口，按商品查询任务状态、结果、供应商编号、费用与退款 |

商品库点击行选择预览，点击标题或编辑进入工作区。来源批发价保存为货源成本，销售价格由用户填写。

产品编辑包含基础信息、主图、详情页、SKU 与规格；推广制作包含图文、视频。每种用途独立持久化草稿，并保留浏览器未保存输入。保存使用修订号，冲突保留当前输入，不静默覆盖。

桌面 1280px 收起全局导航文字，预览栏 360px；宽桌面预览约 390px。界面沿用中文参数、自定义下拉、语义主题与现有浮层互斥机制。

### 商品效果模拟器

包含主图轮播、售价、标题、卖点、颜色尺码、参数、详情图片与禁用的购买样式。明确标注预览模式，不增加销量、评价、认证或服务承诺。

- 只展示当前采用版本，生成完成不会自动替换。
- 标题、价格、规格、顺序跟随商品草稿。
- 具体 SKU 图片优先于颜色共用图片。
- 点击编辑区预览的标题、主图、规格、详情可定位编辑；商品库主图可打开大图。
- 推广制作可切换商品详情和推广内容；视频使用自定义播放器预览。
- 手机外框固定、内部滚动；大图外框固定，支持滚轮、按钮及键盘缩放和拖拽移动。

## 采集闭环

首版适配军埔网 `pc.jp0663.com/detail/:id?site=www` 公开商品。示例：

<https://pc.jp0663.com/detail/d0b3ba64301b48a0aab8c2439b3cc0fd?site=www>

公开页面为客户端渲染；已验证通过其公开商品数据接口获取当前商品资料。首版直接使用该适配器，不依赖登录浏览器、不提供任意网站抓取。

批量一行一个链接，每批 1–20 条。链接标准化后按站点商品 ID 去重，重复链接定位已有商品，用户可打开或重新采集。采集幂等凭据保存在本地，刷新后可核实原请求。

采集顺序为解析、下载、检查、入库。队列持久化、并发 2；关闭页面不影响执行，重启继续未完成项。资源下载最多重试 2 次，部分失败保留已成功内容。

| 内容 | 规则 |
|---|---|
| 标题、供应商、货号、成本、参数 | 来源不可变快照与商品编辑副本分开 |
| 主图、详情 | 按来源区域、原始顺序分类 |
| 颜色、尺码、SKU | 仅保存明确组合，不自动生成笛卡尔积 |
| 颜色和规格图片 | 仅绑定明确来源关系，其他素材供人工选择 |
| 不明确素材 | 保存到来源媒体清单，供素材选择器人工归类 |
| 视频 | 仅来源实际提供时下载，不以图片推断 |

下载原文件，保存来源地址、哈希、尺寸和时间。文件可去重，但用途与位置分别保留。不枚举推荐商品、装饰图或整页截图充当商品素材。

状态：排队中、解析中、下载中、采集完成、部分完成、需人工处理、采集失败。登录、验证码、下架或页面结构变化返回明确原因，不绕过限制。

重新采集产生新的只读快照。用户选择字段和媒体合并；不覆盖销售价格、已确认卖点、推广文案或已采用版本。来源缺失项会提示，不自动删除本地内容。

网络仅允许适配器配置域名；每个请求及重定向检查协议、域名、DNS，固定连接已检查的公开地址，拒绝本机、私网与保留网段，限制大小与时间。

## 产品编辑与推广制作

| 用途 | 输入 | 输出与采用 |
|---|---|---|
| 主图 | 商品图、单张同行参考、场景/人物/构图意图、补充要求 | 指定主图位置或新增位置，逐张采用 |
| 详情 | 商品图、商品资料、逐屏类型/要求/已确认资料 | 一屏一图，手动采用、拖拽/按钮排序，可导出长图 |
| SKU | 颜色或具体规格位置、对应商品图、清理背景/统一构图等要求 | 绑定原颜色或规格，不改货号、价格、尺码 |
| 图文 | 商品图、同行参考图、独立同行文案、逐页要求、标题正文 | 按页真实生成，逐页采用，有序导出图片与 Markdown |
| 视频 | 商品图、可选同行视频、主动反推、可编辑脚本与要求 | 按真实模型时长/比例生成一次完整视频，采用并下载 MP4 |

参考图仅提供创作意图，不承诺绝对保留同一人物。来源参数保留来源标记，AI 不补造材质、尺码、功效或承诺。逐页图文分别编入各自任务提示词，不把其他页要求混入当前页。

视频反推 MP4/WebM 单文件上限 30MB、120 秒，服务端探测真实格式和时长；使用 GEM 原生视频输入。文字润色和图片分析跟随系统辅助模型（默认 TT，可切换 GEM），只有主动点击分析才调用，不随采集或普通生成自动运行。候选插入、替换、取消均由用户决定，迟到结果不覆盖新输入。

视频首版不做剪辑、配音轨、字幕轨、音乐合成。具体时长、比例和附件上限服从配置模型。不能自动换模型、截断要求或用单帧描述冒充视频反推。

### 采用与交付

候选按商品、用途、输出位置关联。主图按位置，详情按模块，SKU 按颜色/规格，图文按页，视频按作品采用。服务端核对完成状态、素材类型、商品和输出位置，拒绝模拟/示例结果。

删除位置、排序、再次生成和切换版本不删除原始文件或历史任务。

ZIP 分主图、详情、SKU 颜色、SKU 规格、推广图文、推广视频目录，附商品资料及采用清单、标题正文、脚本提示词。可合成 750px 宽详情长图（总高最多 60000px）。导出固定当次版本，之后编辑不改变已生成的下载文件。

## 数据与接口

| 实体 | 职责 |
|---|---|
| CatalogProduct | 商品资料、编辑修订、售价、颜色、规格及当前采用 |
| CollectionJob | 采集批次、进度、逐项错误与幂等记录 |
| SourceSnapshot | 不可变来源字段与媒体清单 |
| ProductMediaBinding | 素材用途、顺序、SKU、输出位置及候选关联 |
| ProductCreativeDraft | 商品每种用途独立草稿 |
| CreativeContext | 接单商品修订、用途、草稿修订及输出位置快照 |

旧 ProductProfile 继续服务普通技能；“选择图片并同步资料”显式关联，最多 16 张。超出旧资料名称/内容限制会要求精简，不静默截断同步。

| 方法与接口 | 功能 |
|---|---|
| POST /api/collection/jobs | 提交 1–20 个链接及幂等凭据 |
| GET /api/collection/jobs/:id | 查询采集任务 |
| GET /api/catalog/products | 分页、搜索、状态及归档筛选 |
| GET/PATCH /api/catalog/products/:id | 商品详情及修订保存 |
| POST /api/catalog/products/:id/recollect | 创建重新采集任务 |
| POST /api/catalog/products/:id/merge-source | 合并选中的来源变化 |
| GET/PUT /api/catalog/products/:id/drafts/:purpose | 用途独立草稿 |
| POST /api/catalog/products/:id/creative/:purpose/plan | 固定商品/草稿快照，生成计划及真实报价 |
| PUT /api/catalog/products/:id/adoptions | 更新采用位置与顺序 |
| POST /api/catalog/products/:id/sync-profile | 显式同步旧商品资料 |
| POST /api/catalog/products/:id/export | 固定版本下载包 |
| GET /api/submissions/:key | 核实原生成接单 |

现有 `/api/submit` 接收可选 CreativeContext，旧请求保持兼容。所有变更继续使用本地访问令牌与 Origin 检查。

## 真实生成约束

生产服务启用真实媒体 worker；旧模拟记录仅可读取，生产不运行模拟 worker，也不以示例文件伪装成品。

- 目前真实适配 TT Image 2.5 与 Omni Flash，后端保管版本化凭据。
- 提交前按完整参数和数量查询真实线路价格，检查账户与密钥额度及已预留金额。
- 计划 hash、幂等记录、模型/商品/输入快照固定本次接单；重复点击不重复付费。
- 发请求前先落库。网络中断或重启后提交不明进入待核实，不自动重发付费请求。
- 保存供应商任务号，真实查询状态、费用、退款与结果。
- 文件下载后验证真实图片/视频格式，视频校验时长，再标记完成。
- 下载失败可只重试保存，不重新生成；费用查询可晚于结果保存。
- 缺失凭据、不支持参数或适配器不可用时明确拦截。

## 验收与边界

使用隔离 SQLite 与真实军埔链接完成采集，用同款商品完成主图、详情、SKU、两页图文、4 秒视频及原生视频反推。详见《商品工坊实施与验收-20261029.md》及 reports 原始报告。

自动化覆盖部分失败与重启、去重、草稿隔离、修订冲突、输出位置采用、导出不变性、真实提交一次、提交未知不重发、响应头任务号、凭据版本、下载重试、迟到费用及退款。桌面验收宽度为 1280、1440、1920。

首版站点适配仅覆盖已验证军埔公开字段；站点改版、资源防盗链或新增资源域名需要更新适配器，不声称支持任意电商链接。真实模型生成内容仍需用户审阅，采用是商品交付版本的明确边界。
