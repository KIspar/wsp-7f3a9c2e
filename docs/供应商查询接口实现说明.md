# 供应商账户、任务和模型查询

本次新增七类真实只读查询，复用本机加密保存的 TT / GEM 两把凭据。查询密钥选择与系统默认 AI 辅助模型互相独立，不改变生成设置。账户余额、消费趋势与明细在进入页面时自动查询，每 30 秒刷新；其他查询在点击入口后请求。查询不启动生成或分析任务。

## 页面入口

| 页面 | 功能 |
| --- | --- |
| 全局顶栏 | 账户共享余额、手动刷新、进入算力统计 |
| 算力统计 `/usage` | 账户全部 API 密钥的每日消费曲线、消费明细表，7 / 30 天切换、分页与本页 CSV 导出 |
| 系统设置 `/settings` | 单把 API 密钥的额度、已用、权限与配置 |
| 全部任务 `/history` | 供应商数字任务号查询，显示终态、结果、退款、token、线路与耗时 |
| 模型配置 `/models` | 完整模型目录、按类别筛选与本地搜索、直接查询模型；右侧价格/功能参数面板 |

控件复用共享 shadcn/ui Select、Tabs、Sheet、Field 和自定义 DatePicker；使用全局语义主题变量。查询不会改写本地模拟模型点数或自动开通供应商模型。

## 接口映射

本地接口均为 GET。底层 `/api/provider/*` 的 `credentialId` 支持 `tt-image`、`omni`、`tt-6.1-sol`、`gem-3.8-flash`；账户级接口由后端选择一把已配置的密钥认证，浏览器不能指定模型或密钥来缩小账户范围。后端使用固定供应商域名 `https://api.lk888.ai`、Bearer 认证和中文语言头。

| 本地路径 | 供应商路径 | 参数 |
| --- | --- | --- |
| `/api/account` | `/v1/skills/balance` | 仅返回账户余额和查询时间，不返回密钥额度 |
| `/api/account/usage` | `/v1/skills/usage` | `days=7/30`，固定 `scope=user`；完整每日净消费与期间汇总 |
| `/api/account/records` | `/v1/skills/usage` | `days=7/30, limit, offset`，固定 `scope=user`；明细每页默认 10 条 |
| `/api/provider/balance` | `/v1/skills/balance` | — |
| `/api/provider/key` | `/v1/skills/key` | 仅查询，不提供密钥配置修改接口 |
| `/api/provider/usage` | `/v1/skills/usage` | `scope=key/user`；`days=1..30` 或成对的 `start_time/end_time`；可选 `model`；`detail=0/1`；明细 `limit=1..200, offset>=0` |
| `/api/provider/task` | `/v1/skills/task-status` | 本地 `taskId` 映射为 `task_id` |
| `/api/provider/models` | `/v1/skills/models` | 可选 `type=chat/image/video/audio`，省略为全部 |
| `/api/provider/model` | `/v1/skills/models/-` | `model`，使用 query 传递以兼容带斜杠的名称 |
| `/api/provider/pricing` | `/v1/skills/models/-/pricing` | `model`，可选 `status=active`；页面默认省略，以包含暂停线路 |

供应商响应字段位于顶层。本地包装为 `{credentialId,fetchedAt,data}`；校验必要字段和类型，同时保留完整的未知元数据。超时 30 秒，最大 JSON 8MB，不跟随跳转。异常响应返回可读错误，不泄露原始供应商错误体。

## 算力与费用口径

- 账户余额跨密钥共享，含网页端动账，不能将两把密钥查询到的余额相加。
- `api_key_quota.limit=0` 表示不限额；这时 `remaining` 可省略，页面显示“不限额”。
- 消费接口只包含开放 API 消费，不包含网页端。可查询本密钥或同账户全部 API 密钥；两者不相加。
- 时间范围最多 30 天。账户页使用 7 / 30 天快捷切换；后端按北京时间当天零点确定自然日期范围，明细每页 10 条。小于等于 2000 条时完整读取明细后按日汇总；更大账户查询逐日完整汇总，不使用被截断的记录绘制曲线。底层接口继续支持合法的自定义日期与模型查询。
- 供应商 `cost` 单位是算力，退款后的 `cost` 已是净额，不再减一次退款。未终态费用是预扣/暂记，不能视为最终消费。小额数值可能因供应商精度显示为 0。
- 任务以 `is_final` 判断终态，状态使用机器字段 `state`，不解析中文 `status`。缺失 token 表示“未提供”，不填 0；耗时包含排队，不是视频长度。
- 账户页面和顶栏每 30 秒刷新，可见窗口重新聚焦时刷新；隐藏窗口暂停定时刷新，任务状态改变后更新账户。查询失败保留上次结果并明确提示，缺失费用显示待确认。模型和任务查询保持主动触发，不自动重试付费请求。AI 辅助费用补查在终态后停止；提交不明但有任务号的分析，可通过 GET 取回 `ai_reply`，经过原有候选结果校验后恢复，不重新 POST。

## 完整价格与能力

目录显示所选密钥是否可调用，目录存在不等于已开通。价格保留所有渠道，分别显示运行/暂停、白名单/排除后的路由准入。只有运行、在白名单且未排除才标为可路由；缺失信息不推断可用。

按 token 的模型显示输入/输出每百万 token 单价，不能将 `base_price=0` 理解为免费。按次/按秒的模型显示基础价和最低参数组合起价；选项折算价仅代表一个参数，不能作为整单报价。参考图加价、参考视频、时段折扣、完整计价与能力规则均保留在可展开的完整数据中。功能页展示参数、选项与约束，保留完整端点及渠道约束；不从简介推断未声明能力。

## 凭据与数据

前端只选择凭据标识。密钥在后端解密后仅用于供应商请求；返回前递归移除 `api_key`（包括掩码值）等敏感字段，并清理意外文本回显。HTTP 错误不返回供应商原始正文。查询不保存账户原始响应到 SQLite、任务快照或普通备份；本机已有私有加密凭据仍排除在普通备份之外。分析模型停用不妨碍使用其已保存密钥做只读查询。
