# 商品套图、A+详情与图片爆款复刻实施记录

日期：2026-10-30

## 已落地

- 新增并统一「商品套图」「A+详情」「图片爆款复刻」三个入口，外层技能保留任务工作台；商品工坊产品编辑沿用基础信息页的表单与商品预览布局。
- 商品套图固定白底图 0 张、卖点图 3 张、场景图 2 张、其他图 2 张的默认结构；每个输出位置使用稳定 ID，其他图片必须填写用途。
- 导入 20 个可编辑卖点图版式，预览图片存放在本地模板素材目录；用户界面不展示第三方站点名称、链接或来源文案。
- A+详情使用模块化屏列表，保留重复添加、排序、每屏参考图、适用范围和已确认资料；目标市场、中国和标准详情参数已加入。
- 图片爆款复刻按一张对标图对应一张输出，提供六类复刻类型和参考风格/高度复刻两档，要求填写替换对象。
- 视觉策划与上架文案为主动触发的辅助分析，结果按结构化协议校验，迟到结果不会覆盖新输入。
- 旧「单图复刻（旧版）」不再出现在导航、技能管理或商品工坊；旧地址重定向到图片爆款复刻。商品工坊旧主图草稿读取时投影为商品套图，原始草稿和历史任务仍保留。
- 等待、加载和空结果采用居中反馈；余额位于全局顶部，报价在制作表单的生成操作区显示。
