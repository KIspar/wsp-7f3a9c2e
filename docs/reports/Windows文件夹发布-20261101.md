日期：2026-11-01。目标：Windows 11 x64，通过 BAT 启动本地工作台。

发布目录：`release/AI-Creative-Studio-Windows-x64-20261101/`。双击 `run.bat` 或 `启动工作台.bat`，使用 `停止工作台.bat` 安全停止；`检查运行环境.bat` 检查 Node、SQLite、sharp、Python、FFmpeg、ffprobe 和离线语音模型。

- 已构建的 React 前端、Node 后端、技能、默认资源及 `extensions/douyin-research` 采集插件。

- 空白 `data/`，首次运行初始化数据库；不携带开发机的商品、任务、媒体和 API 密钥。

采集插件通过 Chrome／Edge 的开发者模式加载 `extensions/douyin-research` 文件夹，再在工作台获取配对码。登录和采集必须在安装插件的同一个浏览器中完成。

## 维护

跨平台准备发布目录：先执行 `npm run build`，再执行 `node scripts/package-windows.mjs`。构建机需有本项目的视频 Python 环境及 `.runtime/models/whisper-base`；可通过 `STUDIO_BUILD_PYTHON` 指定构建用 Python。输出目录已存在时使用显式目录和 `--resume` 继续同一次构建，不要指向用户已有数据的工作台目录。

Windows 构建机也可继续使用 `scripts/package-windows.ps1`。Python 3.11 目标依赖固定在 `scripts/windows-python-constraints.txt`，避免升级到仅支持 Python 3.12 及以上的 NumPy 等版本。Node 官方校验和与 PyPI wheel 哈希用于下载校验，完整发布清单供搬运后检查。
