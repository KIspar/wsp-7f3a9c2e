# 选品之神全流程测试执行报告

执行日期：2026-11-01。环境：macOS、Node 24.14.0、系统 Chrome 156、Python Playwright 1.56。测试使用独立 SQLite 和合成商品，不读取日常 `data/`，不使用真实密钥，不产生真实供应商消费。

## 结论

自动化及受控浏览器验收通过。新增 50 项测试，全项目 **26 个测试文件／272 项测试全部通过**；其中研究专项 **59 项**，生产构建通过。连续浏览器旅程通过 **11 组检查**；真正加载 Chrome 采集插件后通过 **5 组检查**。已修复本轮实际复现的五处问题。

这说明本地功能和受控外部响应下的衔接可用。真实抖音已登录页面采集、真实模型生成质量与费用、Windows BAT／DLL 运行尚未通过实机验收，不能据此宣称线上全流程已全部可用。

## 复现并修复的问题

| 问题 | 复现结果 | 修复与回归 |
| --- | --- | --- |
| 供应商补查成功后研究仍停在提交未知 | 分析任务已 completed，研究任务仍 unknown，不能继续 | 研究调度与补查接口只在底层任务已明确完成／失败时恢复调度，仍禁止重发未知请求；断言原 jobId 与提交次数保持 |
| 跨商品复用接单凭据返回原商品任务 | 相同输入、revision 和 key 用于另一商品时返回原任务 | 检查接单凭据所属 productId，冲突返回 409；相同商品并发仍保持一次接单 |
| Chrome 插件配对成功但读不到队列 | 真正安装的 Service Worker GET 没有 Origin，被本地接口拒绝 | GET 使用插件 ID＋配对令牌认证，错误身份、撤销令牌和普通网页 Origin 继续拒绝；真实扩展完成队列读取与采集 |
| 插件读取任务失败后留下采集锁 | 撤销授权后点开始，再配对，active 仍保留旧任务 | 将最初任务读取放入 try／finally，任何读取失败也释放锁；真实浏览器回归已通过 |
| 视频任务缩略图坏图 | 全部任务使用 `<img>` 加载 MP4，截图出现坏图 | 按素材类型渲染视频预览，保持缩略图尺寸；浏览器断言图片 naturalWidth 与视频 readyState |

主要产品修改：`apps/server/research.ts`、`apps/server/research-extension.ts`、`extensions/douyin-research/background.js`、`src/App.tsx`、`src/styles.css`。`apps/server/app.ts` 增加可注入的分析与媒体下载依赖以隔离测试，生产默认路径保持原有服务实现。
