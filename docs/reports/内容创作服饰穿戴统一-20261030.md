# 内容创作服饰穿戴统一

日期：2026-10-30

## 调整

商品工坊的图文、视频与服饰穿戴共用同一个内容创作工作台。切换创作类型只切换右侧操作区，左侧保留共同的任务类型筛选、状态筛选、搜索、任务列表和分页。

- 右侧统一顶部类型标签、保存提示、收起图标，以及底部生成操作区；服饰穿戴保留商品图、模特、场景、姿态等专属输入。
- 全部类型合并展示三类任务，先统一排序和筛选，再以 20 条分页；旧作品查询接口默认行为保持兼容。
- 穿戴任务复用相同的状态、缩略图行、预览抽屉和下载样式，重试后按最新结果判断状态。
- 切换右侧类型不改变左侧筛选、搜索和滚动位置，穿戴草稿独立保存。
- 加载及异常复用工作台公共状态组件，加载提示水平居中。
