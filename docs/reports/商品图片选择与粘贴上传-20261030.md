# 商品图片选择与粘贴上传

## 本次变更

- 商品工坊商品原图采用统一弹窗，默认“当前商品”，可切换“系统图片”。
- 当前商品汇集采集快照、商品绑定图片、商品制作素材及显式关联的外来图片；图片按素材 ID 去重。
- 弹窗首格为“添加图片”，支持本地文件与剪贴板图片。取消只放弃本次选择，已上传的图片仍保留在当前商品图片库。
- 外来商品图片通过独立关联持久化，不修改商品修订、成品位置或未保存草稿。
- 商品套图、A+详情、图文、视频、爆款复刻、服饰穿戴及逐页商品参考共用商品图片选择规则。
- 风格、灵感和对标参考图直接打开电脑文件选择，不进入商品原图分类。
- 普通创作、商品资料、商品工坊、服饰穿戴、素材选择和模板素材上传共用剪贴板图片识别，支持 JPG、PNG、WebP。
- 点击素材区或打开素材弹窗后，可使用系统粘贴快捷键。普通文字粘贴不被拦截；弹窗图片粘贴会阻止向父级重复冒泡。
- 上传期间有明确状态、数量限制与错误提示；重复粘贴或点击不会并发重复上传。

## 验证

- `npm test -- --reporter=dot`：22 个文件、201 项测试通过。
- `npm run build`：TypeScript、前端生产构建、后端构建通过。
- 新增回归覆盖：剪贴板文件与 item 兼容、普通文本粘贴保留、阻止重复冒泡上传、商品图片跨重启持久化、商品隔离与无修订副作用。
- 使用隔离数据库验证真实上传接口；未发起付费模型生成。
- 剪贴板 PNG 经浏览器粘贴，上传成功且仅产生一次上传请求，正确勾选。
- 风格参考入口触发原生文件选择；原生上传及粘贴后加入参考行。
- 商品套图、A+详情、图文、视频和服饰穿戴均验证共享商品图选择器；分类切换正常。
- 1280、1440、1920px 桌面：弹窗宽 850px，水平中心偏移为 0，无横向溢出，添加图片色块首屏可见。
