# UI / UX / 动效评审：已采用的设计决策

日期：2026-10-29。用户回复“采用”后进入实施；随后明确暂不处理手机查看下载。本轮范围为桌面工作流。

## 已确认

- Q1：优先“一款商品连续产出一组成套图”。
- Q2：共享商品原图、名称和已确认参数；用户明确载入，各技能保留独立要求、参考素材与参数。
- Q3：先比较并采用版本，再提供图片合集与详情长图。
- Q4：暂缓手机查看、下载和手机创作适配；本轮只验收桌面。

## 数据与动作边界

商品资料独立保存，载入会复制到当前草稿；更新资料不追改已提交任务。接单持久化成功后当前技能仍回默认值，失败或受理未知保留输入，继续同款需主动载入资料。

采用关系按条目保存，一个条目只采用一个已保存图片版本。重新生成保留旧版，新版本不会自动取代采用版。比较、采用、排版和导出不调用生成模型。

图片合集使用明确的采用版本清单。未完成和未选用项明确提示，不静默补成最新版本。详情长图按组排版，已有排版优先，新的排版仅预选已采用版。已导出文件不随之后改选而变化。

## 保留的约束

- React + TypeScript + Vite、shadcn/ui 自定义控件、中文参数和语义主题。
- 保留深色侧栏与靛蓝品牌色；输入区通过显式收起减少占位。
- 账户余额、预计消耗、实际消费分开；重新生成先报价确认。
- AI辅助仅主动点击调用，候选内容采纳后才修改草稿。
- 当前媒体 worker 仍是模拟；真实账户、报价和AI辅助不等于真实媒体生成。
