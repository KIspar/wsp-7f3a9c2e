# 成套商品图工作流：实施与验收记录

日期：2026-10-29。用户已采用交互方向，并明确暂缓手机相关工作。本轮实施桌面工作流，不接入新的真实媒体生成服务。

## 已实现

- 商品资料：保存原图、名称、已确认参数；明确载入各技能，保留技能独立要求、参考图和参数。覆盖商品字段前确认，解除旧白底依赖。保存有修订冲突检查，未保存关闭有保护；载入未改动资料不增加修订。
- 草稿与快照：资料独立于草稿；接单成功后仍回默认值，失败/受理未知保留输入。已提交任务固定商品资料修订与输入，资料更新不追改历史。
- 紧凑创作框：显式收起/继续编辑，记住各技能偏好，保留摘要。高级参数为次级入口；主动作明确为预览生成。
- 版本比较：按同一条目聚合尝试，两个版本与原始参考可对照查看，输出参数可展开，图片完整展示。采用关系独立持久化，新版本不自动替代已采用版。
- 成套交付：新增侧栏入口，按商品筛选采用图，可调整下载范围。未完成/未采用项明确提示。ZIP包含图片和版本清单，并固定旧导出内容；相同集合缓存并去重导出。
- 详情长图：已有布局优先，新布局仅预选采用版。可手动选版、排序、保存及下载；未保存关闭可继续、放弃或保存。下载按钮明确为保存并下载。
- 历史找回：创作记录优先呈现商品/结果缩略图、技能、时间、成功数与继续入口，AI辅助和供应商任务查询为次级折叠入口。
- 操作反馈：重新生成先查当前报价并确认上限，服务端再次核价；仅重试保存不新调用模型。背景报价刷新保留有效旧数值，刷新失败阻止提交。
- 动效与可用性：Dialog/Sheet有实际进出场动画和减少动态效果样式；关闭恢复触发按钮焦点，关闭名称中文，强化输入焦点和成功状态对比度；切页回到页面顶部。
