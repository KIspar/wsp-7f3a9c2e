# 状态、动效与操作合同验收清单

日期：2026-10-29。状态：设计验收提案；以下不是已通过的测试结果。

关联：`完整评审.md`、`交互重构方案.md`。本表保留评审阶段的完整验收目标，不表示逐项通过；后续实际实施、测试覆盖与未验项见 `实施与验收记录.md`。

## 状态表达

| 场景 | 应显示 | 应允许 | 应阻止或避免 |
|---|---|---|---|
| 首次空白 | 本技能用途、首个行动、素材角色 | 上传、载入明确标识的示例、填写要求 | 把示例当真实生成结果；默认启动AI |
| 草稿有改动 | 正在保存/已保存/保存失败，必要时更新时间 | 继续输入，失败后重试保存 | 旧保存响应覆盖新输入；失败伪装已保存 |
| 素材处理中 | 每张上传/处理状态与失败原因 | 处理无关输入、移除或重试明确失败项 | 未就绪素材混入有效引用；静默漏图 |
| 参数不兼容 | 哪个模型不支持哪种素材/参数 | 保留资料，调整模型或引用 | 静默删素材、暗中换模型 |
| 报价初次查询 | 查询中，数量与当前参数摘要 | 调整输入 | 把未知费用显示为0或免费 |
| 既有报价刷新 | 上次费用/时间+刷新提示 | 查看资料，保持当前焦点 | 整块内容跳位、无解释地反复闪禁用 |
| 参数变更 | 旧报价失效，等待新报价 | 继续编辑 | 使用旧参数报价接单 |
| 余额不足 | 最高报价、可用余额、差额或明确不足原因 | 改数量/参数、刷新真实余额 | 继续付费生成或自动改模型 |
| 计划预览 | 本次素材、数量、模型、参数、费用、来源 | 返回编辑、明确确认 | 展开折叠即付费、混淆真实与模拟 |
| 提交中 | 正在确认受理；本次输入已固定 | 查看其他结果；是否允许新草稿按既有规则 | 多次提交同一动作、提前清空尚未确认草稿 |
| 受理未知 | 正在核实，并说明不会自动重新扣费提交 | 查询/等待同一请求状态 | 换幂等标识自动重提，猜测为失败 |
| 接单成功 | 稳定任务编号和快照，原位任务占位 | 切页、开始新任务 | 延迟保存恢复已消费草稿；清空后来的新输入 |
| 等待依赖 | 等什么、依赖任务状态、明确恢复入口 | 查依赖、执行允许的显式恢复 | 声称执行中或就绪；虚构百分比 |
| 排队/生成/保存 | 阶段文字、真实状态及原位占位 | 切页、看原结果 | 强制滚动、抢焦点、生成假进度 |
| 保存失败 | 生成与保存失败区别、仅重试保存入口 | 保留任务并重试保存 | 默认重新调用付费模型 |
| 生成明确失败 | 简短原因、下一步，诊断可展开 | 修改后确认新尝试 | 自动重试付费请求、丢失原图与快照 |
| 部分完成 | 已完成/总数、失败/未完成，下载范围 | 下载已成功项 | 宣称全套完成或把失败项静默算入导出 |
| AI候选就绪 | 输入快照、模型、候选、是否发生草稿变化 | 插入、替换、取消 | 迟到结果覆盖用户新输入；编造商品参数 |
| 排版有未保存改动 | 未保存标识与当前预览 | 保存、下载、放弃或继续 | 关闭悄悄丢布局；下载暗中行为不明 |
| 刷新失败 | 上次有效数据和时间、失败提示 | 重试、继续查看 | 清空余额/图表造成误以为账户归零 |

## 动效实施边界

建议只用现有组件与少量CSS补齐；不为弹层引入大型动效库。具体时长是提案，可在一次桌面实测中调整。

| 用途 | 建议时长/属性 | 验收 |
|---|---|---|
| 按钮状态 | 100–150ms，color/background/border | 按下立即响应，不等过渡结束 |
| 图像hover提示 | 160–220ms opacity；缩放可取消 | 键盘同等提示，不裁掉商品，不每张图慢慢浮起 |
| Dialog进入/退出 | 180–220 / 140–180ms，opacity和极小位移 | computed动画真实存在；结束后可操作，无透明遮罩 |
| Sheet进入/退出 | 220–280 / 140–180ms，transform+opacity | 到达平稳，快速开关不中断任务，无闪回或重复面板 |
| Select | 即时或80–120ms opacity | 键盘不等动画，Escape返回trigger，长选项避让边界 |
| 内容折叠 | 即时或150–180ms | 箭头、aria-expanded、实际内容一致；不整页逐项入场 |
| 创作框收起 | 180–220ms，仅用户明确操作 | 焦点和滚动锚点合理，返回编辑不丢内容 |
| 任务完成 | 一次短状态强调 | 原卡原位更新，失败不靠颜色独立传达，不强滚 |
| 拖序 | 跟随交互，落位短过渡 | 有占位与落点；键盘上下移动结果一致 |

减少动态：在浏览器实际模拟prefers-reduced-motion，取消位移/缩放，保留可读文字、必要颜色/即时状态；不能仅凭源码存在媒体查询就打勾。装饰spinner可以停转，但“正在查询/保存”等文字必须保留。

## 可执行验收案例

以下每项记录尺寸、步骤、期望、实际、截图/日志及通过状态。涉及生成时使用明确授权的真实调用或隔离的测试执行器；本轮不执行付费调用，测试用例不能被写成真实验收记录。

### 输入与保存

1. 中文长要求、换行、粘贴后，输入可读；AI润色图标不遮文字；放大200%仍可编辑。
2. 连续输入并延迟旧保存响应，最新输入不被覆盖；保存失败不清空文本。
3. 打开参数弹窗、Tab/Shift+Tab循环、Escape关闭，焦点回原按钮；没有可见关闭按钮但读屏只报英文的残留。
4. 素材浮层用悬浮、点击、键盘分别展开；可以从触发器进入浮层操作；退出后回到合理位置。
5. 更换不支持当前素材的模型，显示具体原因并保留待处理引用，不静默删图。

### 报价与接单

6. 参数不变触发后台刷新，数值、焦点和主按钮位置稳定；如果没有有效可用报价，明确阻止确认。
7. 切比例/清晰度/数量后模拟旧报价迟到，旧结果不被当新报价；数量与总价一致。
8. 余额低于本次核价要求，前后端均拦截；输入保留；刷新后按真实新余额重新判断。
9. “预览生成”只打开计划，不发生成调用；“确认生成”才接单，重复点击不重复创建。
10. 确认后模拟响应丢失：同一请求核实，无自动新付费调用；确认受理后仅重置对应输入修订。
11. 结果卡重新生成与首次生成都展示本次模型/费用；保存失败入口仅重试保存。

### 任务与结果

12. 只有排队/等待依赖任务时，顶栏不能显示队列已经空闲；总数与卡片状态对应。
13. 用户查看旧图时新结果完成：不抢焦点、不强滚、不重挂整个列表；完成/失败有可访问状态反馈。
14. 同一item多个版本能对照原图与参考；比较过程中查看详情再返回，保持条目与版本。
15. 采用某版本后新版本成功，不擅自改采用选择；刷新后选择是否保留按最终批准规则验收。
16. 不同批次同为#01，不得误聚合为同一item；旧模拟结果准确标识且不计真实费用。

### 排版与交付

17. 有真实成功样本后，拖序、上移/下移、版本切换所得清单和预览一致；输出不裁切商品。
18. 修改未保存后Escape/关闭，显示保护选项；放弃回原布局，继续编辑保留当前布局。
19. 保存并下载产生与所示版本、顺序、背景、间距、尺寸一致的文件；无新生成调用。
20. 部分成功导出准确列出未包含项；重复下载不重复生成；后台导出能力必须以实际后端验证为准。

### 动效与适配

21. 同一次Dialog/Sheet快速打开关闭，再打开：无闪回、重复overlay、透明阻挡层，焦点正确恢复。
22. reduced-motion下重复上述流程，无位移依赖，依然读得懂加载与完成状态。
23. 1280×720、1440、1920宽度查看横图/竖图；输入展开与收起均不挡最后一项操作。
24. 200%缩放检查字段、菜单、主按钮和弹层边界；不通过缩小字体“适配”。
25. 根据Q4批准范围测试390px：只读路径可查任务、预览、下载；如要求创作，另外验证软键盘与上传。

## 交付证据与通过标准

- 检查表“未测/通过/失败/不适用”分开；未测不作为通过。
- 截图支持布局判断；焦点恢复、动效与幂等需要过程记录或可重复操作，不能只靠静态截图。
- 真实接口以供应商任务号、请求/结果来源、用量和最终费用佐证；模拟不得替代真实调用验收。
- 不泄露密钥；截图/日志/报告只保留配置状态及非敏感标识。
- 本轮没有建立效率基线，不承诺节省百分比；下一轮记录重复上传、跨页比较、找回结果所需操作，再对比方案。
