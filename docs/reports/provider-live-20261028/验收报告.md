## 使用位置

- 算力统计 → 供应商账户与消费。
- 全部任务 → 供应商任务查询，输入供应商数字任务号。
- 模型配置 → 供应商模型与完整价格，打开右侧详情。

查询密钥与系统默认分析模型独立。费用单位统一为算力，未与本地模拟点数合并；普通媒体生成仍处于模拟模式。
