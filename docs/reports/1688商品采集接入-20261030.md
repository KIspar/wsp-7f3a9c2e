# 1688 商品采集接入

日期：2026-10-30。

## 实现

- 商品来源扩展为军埔网与 1688，按站点和商品编号去重；标准化桌面及移动 offer 链接，移除跟踪参数，拦截编号冲突与其他域名。
- 读取商品页面明确提供的标题、供应商、货号、原始参数、货源成本、主图、详情、视频和实际 SKU；不生成规格笛卡尔积，不把批发价当售价，不抓取推荐区素材。
- 后台直接读取公开页；需要动态渲染时使用新建、无登录状态的本地 Chrome。浏览器仅允许适配域名，DNS 固定为已校验公网地址，阻止私网、任意重定向、下载和 WebSocket。不操作验证码，不读取用户浏览器账号或 Cookie。
- 自动读取受阻时显示“需人工处理”，在商品行及编辑页提供“补充页面文件”。用户正常打开页面后保存 HTML 即可导入，限制 8MB，校验商品编号，仅解析 JSON，不执行来源脚本，不保存完整 HTML 或登录数据。
- 页面补充及采集继续使用现有持久化队列、素材校验、去重与来源合并机制。重采不覆盖人工修改，异步解析期间的编辑也保留。
- Chrome 为可选运行依赖：缺少 Chrome 时给出说明，HTML 补充仍可使用。Playwright 已提升为生产依赖，并同步 lockfile；注册源在当前环境不可用，使用项目已安装并锁定的 1.64.1。
