# 当前结果与任务历史简化

## 已交付行为

- 删除比较弹窗、左右结果比较、结果编号标签、模板及作品的历史切换下拉、手动采用结果入口。
- 图片、商品套图、A+详情、SKU、图文、视频分镜生成成功并验证文件后，自动更新对应位置的当前结果。
- 失败或提交待核实保留已成功成品；较早请求迟到不会覆盖较新的成功结果。
- 分镜首帧和片段自动绑定，只有匹配当前镜头内容与首帧的结果可进入当前合成。合成成功后自动保存内容作品。
- 文案和排序仍可保存，不需要额外确认生成结果。
- 全部任务默认显示最近 7 天，可切换 30 天或全部时间。按任务展开全部历史生成内容，支持预览、单项下载、整组 ZIP、复制提示词。
- 本地合成成片单独列入全部任务，支持 MP4、分镜复制和成片/分镜合集下载。
- 不删除历史任务、原始文件或旧成品。内部任务关联与兼容字段保留，用于历史记录和恢复；当前界面不再提供历史结果切换。

## 数据处理

首次启动通过 `automatic-current-results` 迁移标记，将已有真实成功结果整理为当前结果。重复启动不重复迁移，也不调用供应商生成接口。
