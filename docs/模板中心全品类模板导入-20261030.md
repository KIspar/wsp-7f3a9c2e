## 使用

打开「模板中心 → 图文」，按分类标签筛选；查看三张示例和三页编排后，选择已有商品，将模板带入图文草稿继续编辑。模板不会直接触发图片生成或分析调用。

- 导入记录：`data/imports/designkit-shoppable-20261030.json`、`data/imports/designkit-remaining-20261030.json`。

- 本次未调用付费接口；正式服务无需重启。
