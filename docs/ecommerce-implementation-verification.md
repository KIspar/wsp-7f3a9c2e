## 与参考站仍有差异的部分

1. 手机上传／跨设备扫码上传尚未接入；当前支持本地上传、粘贴、拖拽及素材库。
2. 部分页内高级模板和专属流程采用共用参数与提示词实现，未全部达到原站逐项交互一致。
3. 局部编辑选区作为黑白参考图传给模型，不是模型原生蒙版参数，不能保证选区外像素完全不变；再次打开编辑会从空选区开始。
4. 搭配矩阵的抽样目前是可重复的确定性抽样。
5. 已有响应式样式，但尚未完成所有页面在手机、平板与不同桌面尺寸下的验收。
6. 文案与检测页面使用共用分析执行器，各页面的真实模型成品尚未逐个验证。
7. 系统按钮、弹窗和表单保留现有组件与主题色；步骤标题按截图采用蓝色。因此当前不是全站逐像素一致的版本。
8. 电商详情页的逐模块张数、草稿大纲编辑、部分推荐方案／词库快捷入口、AI 帮写和附加功能的二级配置尚未全部对齐；仍有页面使用共用执行参数。当前检查不包含这些流程的完整验收。
9. 主图拼图的 7 个分类按布局语义归类；已经实测本地筛选，但尚未逐个核对与原站分类集合完全相同。

当前可确认：143 个电商页面的基础布局与素材已接入，代表性交互及全部本地工具已实际验证。上述差异仍需继续对齐，不能将本记录视为「所有功能已完全一比一复刻」的验收结论。
