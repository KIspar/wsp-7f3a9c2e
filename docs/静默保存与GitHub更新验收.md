# 静默保存与 GitHub 更新验收

版本：0.1.1，补丁 0.1.2、0.1.3。环境：本机 Node.js 24，BrowserOS neo 可见浏览器。无需自有服务器。

## 保存行为

- 画布修改合并、防抖，输入、拖动和缩放期间暂停提交；正常保存不弹通知、不切换按钮状态。
- 画布投影、JSON 编解码和网络保存交给 Worker；常规 JSON API 和本地草稿 IndexedDB 也使用 Worker。
- 商品、分析、模板、研究及视频编辑草稿改为异步缓存。仅保留轻量偏好及必要的付费幂等安全记录同步存储。
- 写入期间发生的新编辑继续保留；切换画布、执行生成与安装更新前等待必要保存。保存失败仍明确提示并支持重试。
- 不能承诺主线程零开销：React 更新、交互处理和消息结构化复制仍有成本；本次重点移除频繁序列化、同步草稿写盘及保存状态刷新。

## 实际界面验证

1. 新建临时画布，添加文本、输入、拖动和缩放；未出现保存中或自动保存提示。
2. 刷新页面后文本与位置恢复。临时画布已删除，返回原「123」画布。
3. 新建模板输入名称、提示词与标签；关闭后刷新，再打开恢复内容。发现标签显示遗漏，修正后重新验证通过。测试字段已清空，未生成付费任务。
4. 版本弹窗显示当前版本、检查/下载/安装入口及自动检查、自动下载选项。
5. 未授权私有仓库时，手动检查显示本机 GitHub 授权错误，未误报为最新版本。
