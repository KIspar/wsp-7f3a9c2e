# 模型接入与一键推荐

日期：2026-11-09

## 产品流程

模型配置 → 创建 API Key 指引 → 填入中转站密钥 → 连接并同步 → 检查推荐 → 一键启用推荐。

- 初和、Token01 继续独立管理密钥、权限、余额和分组。
- 创建密钥时，平台若提供「全部模型／不限制模型」可选择；没有该选项时保留平台默认设置。
- 推荐区分别展示图片创作、视频生成、AI 辅助的模型、来源、分组策略、推荐理由及可用数量。
- 高级设置保留手动选择模型与分组；从推荐切换为手动时自动展开。
- 创建密钥指引和帮助页承接详细解释。

## 推荐边界

推荐只考虑已经适配、已同步权限且本地凭据版本一致的模型。仅保存密钥而未同步，不视为可用。当前使用固定适配优先级，并非实时质量排名、最低价路由或自动故障切换。

| 用途 | 当前优先顺序（内部模型 ID） |
| --- | --- |
| 图片 | tt-image |
| 视频 | minimax-h3-fast → omni → gk-video-3.5 → minimax-h3 |
| AI 辅助 | gem-3.8-flash → gem-4-argon → tt-6.1-sol |

已经启用的推荐仍然可用时继续保留。预览不修改配置；应用时只启用选中的模型，其他模型的开关保持原值。预览过期时拒绝应用，要求刷新。

系统沿用初和密钥的渠道策略，以及 Token01 密钥绑定的分组。已有显式模型／密钥／分组绑定不被替换。未绑定模型可使用已经验证的附加密钥或分组密钥；附加密钥的手动分组标注须与本地目录匹配。不会调用中转站接口修改分组，也不增加上游未支持的切组参数。

推荐作用于新建通用创作草稿、新画布节点及 AI 辅助默认模型。已有保存或编辑过的草稿、专属工作流配置、任务快照保留原值。启用推荐不会触发付费生成；创作费用仍使用现有生成前查询流程。
