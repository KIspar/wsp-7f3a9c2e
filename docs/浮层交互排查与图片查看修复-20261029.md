# 浮层交互排查与图片查看修复

## 本轮确认和修复

1. 参数下拉可以同时保持打开。已在共用 Select / Popover 层协调开关，同级及跨类型菜单切换时关闭旧菜单；退出动画仍保留，但不接受点击。旧菜单退出时不再把焦点抢回旧入口。
2. 素材面板进入示例弹窗后，关闭弹窗会丢失焦点到 body。弹窗现在记录可存活的返回入口：来自浮层里的操作会返回其素材入口；嵌套图片预览返回版本比较中的图片按钮。
3. 图片读到真实尺寸后，竖图触发外框宽度从 1140px 变成 760px。已移除按图片方向改变外框的规则；固定外框和内部可滚动画布分离，图片加载和缩放不会改变弹窗布局。进入只淡入，不对外框做缩放动画。
4. 图片预览原来仅底部按钮缩放，且每次缩放都跳回左上角。已加入鼠标滚轮缩放、以鼠标位置为中心保持观察点、拖拽平移、原始尺寸和适应窗口。拖拽结束、取消、丢失指针捕获或窗口失焦会清理状态。
5. 静态审查发现共用 Button 未默认指定类型。为表单里的操作按钮补上默认 `button`，原有显式 `submit` 保留；非紧凑素材缩略图也显式指定 `button`。浏览器验收中“高级参数”只打开参数矩阵，未观察到误提交，本项属于预防性加固。

## 图片查看操作

- 滚轮：围绕指针放大 / 缩小。
- 拖拽：图片超出画布后平移查看。
- 画布获得焦点时，`+` / `-` 缩放，`0` 原始尺寸，`F` 适应窗口。
- 放大上限 800%；缩小下限为 10% 或适应窗口比例中的较小值。

本轮聚焦桌面交互状态与图片查看，不代表全系统不存在其他缺陷。未做移动设备、屏幕阅读器及真实慢网节流验收。
