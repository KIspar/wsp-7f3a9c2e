# 图文双模式实施与验收

完成时间：2026-10-29。工作区：商品工坊 → 商品 → 推广制作 → 图文。

## 已交付

- 左任务列表、右创作栏；创意生成与逐图复刻分别保存草稿。
- 商品图和同行图上下分行、组内横排；支持本地直接上传、素材库、移除、编号、固定尺寸大图预览。
- 创意生成：灵感图最多 4 张，只主动分析，不发送给出图模型；“提取画面灵感”直接执行、追加最新要求、支持撤销。
- 逐图复刻：对标原图最多 20 张，勾选决定实际页数；必填替换对象；每张可展开设置独立商品图、对象和局部要求。
- 报价、接单、版本与导出使用同一份勾选页投影；稳定输出位置不因取消勾选而串页。
- 模式迁移保留服务端原文档、浏览器未保存输入、待核实提交和旧通用参考用途提示；浏览器原值留存备份，不改幂等凭据；复刻沿用来源模式和确认后的页序。
- AI 分析关联原模式草稿，原子应用防重复，提交下一条任务后不应用旧结果；失败或提交未知不自动重发付费调用。
