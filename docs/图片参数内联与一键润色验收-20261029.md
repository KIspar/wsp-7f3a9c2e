# 图片参数内联与一键润色验收

日期：2026-10-29。

## 已实现

- 商品工坊推广图文的六项模型／技能参数直接放在创作侧栏，取消图片「更多参数」弹窗；复用 Properties 和现有自定义下拉，参数保存与报价协议不变。
- 全系统 AI 润色入口改为一次点击提交文字润色，处理时显示加载状态，完成直接回填并提供撤销，不需要选择素材或二次确认。
- 图文、视频、商品与普通技能按各自命名空间保存未完成润色请求；失败、空结果、超长结果和期间的新输入不覆盖原文。
- 提交未知只查询原请求；核实可补查已有供应商任务状态，不重新提交付费请求。可结束本地等待，任务及分析历史仍保留。
- 提炼卖点和图片／视频反推保留原有素材选择及候选面板。

## 验证

14 个测试文件、138 项测试通过，TypeScript 与生产构建通过。1280／1440／1920px 检查参数直接可用，无横向溢出、页面额外滚动或参数弹窗；生成入口固定。

真实 TT 文字润色调用一次，供应商任务 195214792，本地任务 analysis-478b5b46-ebca-457b-a8bf-2c34404b5933。点击即接单且无确认弹窗，最终返回 259 字内容，浏览器核实后成功直接回填。最终输入 468 token、输出 237 token、消费 0.0017 算力，重复付费提交 0 次。

这次供应商处理超过本地 240 秒超时，本地正确进入待核实并保留原文。通过账户消费记录唯一对应的模型与创建时间取得任务号，并查询供应商任务状态，恢复完成结果和最终费用；这是本轮已知测试请求的人工核实，没有新增自动按时间匹配任务的逻辑，也未重发生成。
