# 商品工坊三区工作区与加载状态

日期：2026-10-30。范围：商品详情中的导航、内容创作、逐帧复刻与等待/失败反馈。这是沿用既有界面的局部扩展，采用 Operate 方向。

本记录更新当前导航口径。`推广制作实施与验收-20261029.md`、`视频三模式交互优化-20261030.md` 与早期逐帧复刻记录保留为历史；其中把逐帧复刻放在普通视频模式内的描述，由本记录替代。

## 工作区边界

| 顶部工作区 | 内容与职责 | 地址状态 |
| --- | --- | --- |
| 产品编辑 | 基础信息、主图、详情页、SKU 与规格；维护商品事实和商品素材 | 默认地址，无 `tab` 参数 |
| 内容创作 | 图文，以及普通视频的「直接生成」「参考视频反推」；延续作品记录与独立创作草稿 | `?tab=promotion` |
| 爆款复刻 | 原视频拆镜头、替换商品、确认首帧和片段、合成成片 | `?tab=remake` |

原「推广制作」对外更名为「内容创作」。普通视频导航只显示两个制作方式，逐帧复刻拥有独立顶部入口。内部沿用 promotion/remake 标识与既有接口，不以界面命名迁移持久数据。

商品标题、保存状态、来源、任务与下载操作仍在公共标题区。产品编辑的当前小节保存在同一商品编辑组件中，切换顶级工作区后返回仍保留。内容创作中的图文/视频切换沿用独立草稿；普通视频方式在切换前先保存当前草稿。已有作品若属于逐帧复刻，其「复刻」入口转入爆款复刻工作区。

## 爆款复刻四阶段

| 阶段 | 主工作区 | 右侧操作区 |
| --- | --- | --- |
| 分镜反推 | 镜头导航与原视频首帧、已确认首帧、已选片段对照 | 镜头证据、语音文本和可编辑提示词 |
| 商品首帧 | 当前镜头与商品首帧对照 | 首帧重绘、商品替换要求、候选与报价入口 |
| 分镜视频 | 当前镜头和选用片段对照 | 已确认首帧、动作提示词、视频候选与报价入口 |
| 合成成片 | 成片候选选择、播放、确认与下载 | 已选片段、时长规格、音轨设置和本地合成 |

阶段导航显示当前步骤与完成情况；镜头横向导航显示镜头、时间范围和选用状态。历史任务与候选继续从现有接口读取，已打开的任务按商品保存在 `remake-open:<商品 ID>`。恢复时依据已有首帧、片段和成片推断合适阶段。

待选媒体保留固定比例和空位说明。首帧与片段以用户选用结果为准；成片页继续明确本地合成和音轨规则。页面不增加新的装饰图片，使用实际商品素材、参考视频及已存在候选。

## 加载、失败与播放状态

| 场景 | 界面反馈 | 恢复方式 |
| --- | --- | --- |
| 首次打开商品 | 保留标题、三项工作区导航和双列结构的商品骨架 | 商品读取完成后进入编辑器 |
| 内容任务首次读取 | 任务卡片轮廓骨架和明确的读取文案 | 数据到达后显示作品 |
| 草稿恢复 | 素材、输入框、参数与主操作位置的 composer 骨架 | 草稿到达后恢复编辑 |
| 镜头及操作面板恢复 | 四阶段与媒体对照轮廓的 shots 骨架，侧栏使用 composer 骨架 | 镜头/草稿到达后恢复工作区 |
| 首次读取失败 | 就地错误标题、说明和「重新加载」 | 对应查询重新读取；商品入口另可返回商品库 |
| 后台刷新失败且已有内容 | 保留上次数据、已读任务或镜头，在原区域显示可重试错误 | 重试刷新，继续使用已有内容 |
| 视频首次加载或缓冲/跳转 | 媒体区域覆盖「正在载入视频…」或「视频缓冲中…」 | 已载入、可播放、开始播放或跳转完成时退出覆盖层 |
| 视频媒体致命错误 | 媒体区域错误说明与「重新加载视频」 | 调用当前媒体重新加载 |
| 播放未启动或全屏不可用 | 独立提示文案 | 用户可再次播放或继续使用可用操作；不切换为媒体致命错误 |

共用 `WorkspaceLoading`、`WorkspaceError` 和 `CatalogEditorLoading`，等待状态使用 `role=status`，错误使用 `role=alert`；骨架形状为辅助技术隐藏内容。视频状态覆盖不改变画面和自定义播放条的基本几何。

减少动态效果设置下关闭新增骨架和视频载入图标动画；工作台沿用既有的减弱动画规则。侧栏阶段切换的小幅淡入只在允许动态效果时启用。

## 沿用的视觉与组件

视觉依据为既有 `全局视觉与组件规范.md` 与 `src/styles.css`：深色侧栏、紫色主操作、浅中性内容底和白色容器。主题颜色继续引用 `primary`、`accent`、`muted`、`border`、`foreground` 等语义变量。中文字体、字号层级、圆角、焦点和动效继续使用项目原有体系。

复用项目 Button、Tabs、FormSelect、NumberInput、Slider、Popover、素材选择器与自定义 VideoPlayer，不引入另一套可见原生表单或播放器控件。

主区承担任务/预览，右侧承担当前任务输入与操作，二者独立滚动。侧栏在已检查桌面宽度下按既有规则取 480px（不大于 1400px）、520px（常规桌面）和 560px（不小于 1800px）；不把这些桌面检查扩展为手机适配结论。1280px 下沿用窄侧栏模式，减少导航占用。横向镜头轨道在容器内滚动。
