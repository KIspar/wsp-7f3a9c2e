# 全局视觉与组件规范

2026-10-28 更新。主要视觉依据为用户提供的 `ai_creative_studio_studio (1).tsx`；它替代早期原型的紧凑、小圆角外观。参考文件用于视觉与交互参考，实际任务、技能、模型和算力仍由现有后台提供。

## 全局视觉

- 深色侧栏宽 256px；白色顶栏高 56px；工作区使用浅灰底色和 24px 留白。
- 主色为靛蓝；选中的导航和主要执行按钮使用品牌渐变。
- 任务批次、管理面板采用白色圆角卡片、细边框、轻投影；卡片圆角 16px，控件约 10–12px，弹窗 24px。
- 普通技能共用贴底的紧凑两行输入台：素材与自适应输入框在上，参数与生成操作在下；默认高度约 114px。参考图改为横向入口，仍可悬浮、点击或键盘打开素材面板。自动保存并入输入行，算力改为行内提示。输入台宽度与结果工作区对齐，长文本增长与窄窗口换行时，结果区底部避让随实际高度同步。
- 图片卡片统一 3:4 预览窗口，悬浮或键盘聚焦可放大查看；原图在预览中完整展示。模拟素材始终标注。
- 所有管理页面、智能体工作区、参数弹窗、素材浮层和状态反馈共用上述规则。

## 技术与组件

React + TypeScript + Vite；基础控件集中于 `src/components/ui/`，沿用项目 shadcn/ui 的 Radix 基座和组合方式。Tailwind CSS 使用 `background`、`card`、`primary`、`accent`、`muted`、`border`、`ring`、`success`、`warning`、`sidebar` 等语义主题变量；颜色只在 `src/styles.css` 的主题声明中定义。

- 下拉：`Select` / `SelectTrigger` / `SelectContent` / `SelectGroup` / `SelectItem`。业务字段通过公共 `FormSelect` 传入选项与值，不使用原生选择弹窗。
- 日期：`DatePicker` 组合 `Popover`、`Calendar`、`Button`、`Select`；年份、月份均使用相同 Select。日期筛选与显示统一按本地日期处理。
- 数字：`NumberInput` 组合 `InputGroup`、`InputGroupInput`、`InputGroupAddon` 与按钮，支持上下键、范围约束和自定义步进。输入台数量使用统一下拉。
- 勾选：`Checkbox`；布尔设置使用 `Switch`；筛选组使用 `ToggleGroup`。
- 确认：`ConfirmDialog` 组合 `AlertDialog`，替换浏览器 `window.confirm`。
- 视频：自定义播放条，使用 `Button`、`Slider` 和 `FormSelect`，不启用浏览器原生 controls。
- 上传：页面入口使用自定义按钮、拖拽、粘贴和素材浮层；文件读取保留隐藏 file input 的浏览器安全机制。

保持键盘操作、焦点恢复、禁用与选中状态、弹层边界避让，以及减少动态效果设置。可见控件不使用原生 select、date/time、number、checkbox、range 或浏览器确认弹窗。

## 字体与排版

- 全局使用同一中文优先的无衬线字体栈：苹方、微软雅黑、Noto Sans CJK SC、平台字体；代码与技能源文件使用等宽字体，中文沿用全局回退。无外部字体请求。
- 根字号保持浏览器默认的 100%（通常 16px），支持浏览器字号设置与缩放。
- 语义字号集中在 `src/styles.css`：`text-body` 16px、`text-control` 14px、`text-caption` 13px、`text-micro` 12px、`text-page` 24px、`text-section` 18px、`text-dialog` 20px。以上为默认浏览器字号下的值。
- 主导航使用正文级 16px、中等字重，选中时加至 600；分组、状态和辅助文字使用 13px，少量徽标使用 12px。侧栏可滚动，窄窗口不缩小文字。
- 正文 400、操作与标签 500–600、重点信息 600–700，避免通篇粗体；长段落约 70ch，正文行高 1.625。
- shadcn 基础控件共用全局字体和 Tailwind 字号尺度；工作台、管理页、弹窗和素材浮层不各自定义字体。
