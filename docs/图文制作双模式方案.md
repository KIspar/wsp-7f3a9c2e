# 图文制作：创意生成与逐图复刻

采用左侧任务记录、右侧创作栏。1280 / 1440 / 1920 桌面侧栏分别为 480 / 520 / 560px；图文和视频沿用各自创作入口。

## 两种图文模式

| | 创意生成 | 逐图复刻 |
|---|---|---|
| 目的 | 探索商品穿搭、场景与表达 | 将同行画面指定商品替换为自有商品 |
| 商品图片 | 外观与可见细节依据 | 公共参考，可逐张覆盖 |
| 同行图片 | 灵感参考，可选 1–4 张 | 对标原图，最多 20 张，受批次上限约束 |
| 输出数量 | 独立设置页数 | 仅勾选原图，每张一页 |
| 分析 | 点击“提取画面灵感”才分析 | 可直接复刻，不隐含分析费用 |
| 同行图参与出图 | 不发送 | 只发送当前页原图 |

两种模式按商品独立保存图片、要求、文案、编排与参数。切换不复制、不覆盖、不收费。任务卡、版本清单、下载包保留模式。

## 右侧创作栏

商品图片与同行图片上下分行，组内横向排列，提供图号、预览、移除和末尾本地上传入口；标题右侧素材库图标选择已有素材。超限文件整批拒绝，不能静默截掉。

创意模式：商品图片 → 可选灵感参考图 → 提取画面灵感 → 图文要求 → 编排 → 内联参数 → 固定报价入口。

复刻模式：商品图片 → 对标图组与勾选 → 必填替换对象 → 整组要求 → 逐图展开设置 → 内联参数 → 固定报价入口。

逐图设置包含本图商品参考、替换对象覆盖和局部要求。取消勾选保留设置；移除只解除引用，不删除文件。输出位置绑定原图 ID，不按勾选后的数组下标串页。

## 画面灵感与安全应用

只提炼场景、人物可见造型与姿态、构图、光线、配色、排版和画面节奏，不复制同行商品事实或无依据承诺。默认系统辅助模型，沿用凭据、TT 识图验证、任务队列和费用查询。

点击即分析，无二次弹窗。结果追加“参考画面建议”到最新要求，保留分析期间的新输入，可撤销整段；被编辑过的段落不会强制删除。切换模式后结果留在原草稿记录，再进入创意模式可应用。已经提交任务的旧结果只保留，不写进下一条任务。

任务与草稿关联事务保存；应用记录和草稿修订也在同一事务内保存。刷新、重复轮询和并行页面不会重复追加。失败、缺失凭据、未通过识图验证和提交未知保留输入，不重发付费请求。

## 生成与兼容

报价、提交、候选版本和导出共用勾选页投影，快照保存实际参与生成的页。公共或逐图要求、素材、勾选与模式变化后须重新报价。复刻保留场景、人物可见外观、姿态、机位与构图，以自有商品图决定颜色、版型和细节；人物一致性受模型能力约束。

接单后保留商品图和常用参数，清空一次性要求、同行图、文案和逐图设置。生成期间可以准备下一条。

旧草稿有对标图组时迁移为逐图复刻，无图组时为创意生成。原文档留存；旧通用参考图显示“待指定用途”，明确选择用途或移出引用后才能报价，不能静默更改含义。跨商品复刻清除来源商品事实及自有图，保留明确标注的来源结构和对标画面，要求重新填写目标替换对象。

计划校验值使用按键排序后的内容，避免 API 校验重排对象字段造成误拒绝；不放松商品修订、草稿修订与实际素材快照校验。
