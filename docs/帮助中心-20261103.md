# 帮助中心与页面说明整理

入口：`/help`。左下角「帮助中心」打开完整目录，顶栏帮助图标按当前页面及商品工作区打开对应主题。

帮助正文统一维护在 `src/lib/help.ts`，当前包含 11 个主题、40 篇说明。支持跨主题关键词搜索、折叠阅读、返回功能页面；主题和搜索条件保存在 URL，刷新后可恢复。主题切换回到页面顶部。

将模型配置、图片与视频创作、服饰穿戴、商品工坊、选品研究、内容复刻、模板、费用与备份等页面的重复教程集中到帮助中心，移除原简短使用说明弹窗。保留字段名称、素材限制、价格与倍率、当前状态、校验错误、付费确认和覆盖草稿等必要信息。

后续说明优先更新帮助正文。业务页面仅保留当前操作需要判断的信息，避免重新添加整段背景介绍或重复教程。
