## 自动化

`npm test`：**13 个测试文件、134 项测试通过**，其中推广专项 14 项、会话恢复专项 4 项。

推广专项覆盖：

1. 未首次保存的默认草稿输出位置稳定，可直接接单。
2. 原子写入作品／版本、仅清理本次字段，幂等回放不重复建任务。
3. 上一条排队时继续接单，图文、视频及商品级旧文案隔离。
4. 过期草稿和错误关联拒绝，事务不留下孤立批次。
5. 服务重启后恢复原接单记录和重置草稿。
6. 部分页失败保留成功页，单页补做，未补齐不能确认整组。
7. 确认版本及纯文案／顺序修订不可变，不新增生成请求。
8. 跨作品、跨页和模拟结果不能确认。
9. 同款复刻保留来源，替换前备份，重新生成复用作品位置。
10. 跨商品替换图片与事实，来源原始文案不进入目标生成提示词。
11. 历史迁移重复运行不重复建作品，不伪造历史标题正文。
12. 效果空值／零值、跨商品值得复刻查询、ZIP MIME、固定版本与商品整包导出。

`npm run build`：TypeScript、Vite 和服务端构建通过。现有前端单包约 920 KB，构建提示分包建议，不影响本次功能验收。

实测交互：

- 图文／视频切换分别恢复已有不同草稿，不互相覆盖。
- 收起输入区后展开内容退出焦点与可访问树，展开可继续编辑。
- 自定义参数下拉同时仅一个处于打开状态；Escape 关闭并返回触发器焦点。
- 作品抽屉覆盖显示，不重排右侧创作栏。
- 用已保存真实图片新建纯文案修订，界面出现新确认版本，旧版本仍可选择。
- 将确定版本标记值得复刻，并人工保存「播放 0、其他指标空白」，界面分别显示 0 与未填写。
- 复刻检测现有草稿，未勾选备份替换时禁用载入；确认后正确恢复来源标题正文到独立草稿。
- 复刻载入不创建生成批次。

证据：`docs/reports/promotion-20261029/`，包含不同视口截图及 `workflow-evidence.json`。

## 跨商品复刻的处理界限

无法只靠替换商品名称可靠去除源文案中的全部事实。跨商品复刻会把完整来源结构保存为只读参考，目标提示词使用中性页结构／镜头骨架，并要求用户按目标商品改写。来源参考不自动发送给生成接口。

效果来自人工填写，不接账号、发布、投放或自动数据采集。
