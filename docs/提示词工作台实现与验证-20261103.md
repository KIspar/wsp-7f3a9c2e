# 提示词工作台：实现与验证

日期：2026-11-03

首版代码已实现；类型检查、生产构建和完整回归测试通过。BrowserOS neo 的可见界面验收使用独立端口 4381、临时数据库及确定性模型响应，没有使用真实密钥或发起真实付费生成。

## 已交付能力

- 智能体新增「提示词工作台」，入口 `/agents/prompt-workbench`。
- 项目搜索、独立创建、从商品工坊导入快照；一个商品可保留多轮独立创作。
- 六步流程：商品与素材 → 商品卖点 → 选择方向 → 脚本与分镜 → 提示词与解释 → 检查与导出。
- 一键生成多套脚本，也可逐步策划。默认四套，可选一至六套，按已有辅助队列顺序执行。
- 卖点保留原文依据；未确认事实、缺资料和冲突不升级为已确认商品事实。
- 最多九张素材，按商品、人物、场景等用途绑定。识图任务按最多四张分批执行。
- 逐镜修改画面、动作、镜头、台词和时间；支持仅调整一套方向或一段脚本、提示词。
- 六模块提示词、参考图编译、整片和分段视图、策划解释。
- 自动保存、本机未同步编辑恢复、成果版本、版本比较和恢复、AI 结果冲突时保留候选。
- 本地结构检查加 AI 检查；检查绑定内容版本。修改后旧检查失效，局部修正检查不能代替整片检查。
- 正式交付、草稿导出、Markdown、文本、项目 JSON、保存选中方案到模板中心。
- 视频草稿交接：核对单段时长、比例、参考图上限、已配置模型与分组；不自动发起视频生成。
- 替换视频草稿前自动备份；「版本 → 视频草稿备份」可恢复，恢复时也备份当前视频草稿。
- 调用费用确认、预算暂停与继续、停止后续步骤、未知接单结果先核实、已完成调用不重复提交。
- 操作说明集中在帮助中心；任务详情可返回原创作项目。

工作台新增 14 项服务与领域测试，覆盖完整流程、九图分批、幂等接单、部分失败保留、编辑冲突、未知请求不重发、台词锁定、局部失效、正式检查范围、模板来源、视频草稿备份恢复、素材图号去重、事实引用、预算暂停继续、模型与密钥变更、历史恢复和独立新轮。

BrowserOS neo 通过可见点击、输入与选择完成：

1. 从商品工坊导入测试商品，修改资料，应用版本并刷新确认保存。
2. 确认调用范围和费用，一键完成四套脚本，再生成四套提示词。
3. 查看方向卡及分镜页面截图，确认布局和控件呈现。
4. 提交单段调整，确认仅一次阶段调用。
5. 检查当前提示词，保存方案到模板中心。
6. 手改台词后确认提示词待更新、正式导出禁用；恢复历史版本并确认旧内容完整保留。
7. 带入兼容的四秒、9:16 视频草稿，确认图片和提示词传递，未提交视频生成。
8. 从版本面板恢复原视频草稿，确认原模型、空白要求和零张参考图恢复。
9. 创建第二轮，确认沿用商品资料，方向和脚本独立。
10. 项目搜索、无结果状态、帮助中心入口。
11. 全部任务中的 AI 辅助记录可打开工作台阶段详情，并通过「返回创作项目」回到正确项目。

## 当前运行状态与边界

- 现有 5173 开发页面使用的后端进程启动早于本次改动，需重启开发服务才能加载新增 API。此次侧对话未重启该服务，避免打断主对话正在执行的任务。
- 新功能已包含在构建产物中。开发服务下次执行 `npm run dev` 时会加载新增后端及页面。
- 隔离验收不代表真实上游模型的输出质量或视频成片已通过验证。视频生成仍需用户在生成页查看真实报价并提交。
- 来源链接只记录；网页正文需粘贴或从商品工坊导入，不宣称已经自动读取链接。
- 首版每个生成段不超过十五秒、整片不超过六十秒；实际交接遵守视频模型支持的时长档位。
- 多段批量生成、自动拼接和统一音轨字幕未纳入首版。
- 提示词工作台复用已配置的默认 AI 辅助模型，不新增密钥输入或绕过中转站分组限制。
