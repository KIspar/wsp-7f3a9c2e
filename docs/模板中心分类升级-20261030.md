# 模板中心分类升级

原「提示词库」统一更名为「模板中心」，正式路径 `/templates`。旧 `/prompt-library` 自动跳转并保留查询参数；底层 API 和历史版本 ID 不变。

| 一级分类 | 内容 | 创作入口 |
| --- | --- | --- |
| 图文 | 整组要求、逐页编排、组图效果与参考 | 商品工坊 → 内容创作 → 创意生成／逐图复刻 |
| 图片 | 图片提示词、构图要求、效果与参考 | 独立图片创作技能、商品产品编辑的图片制作 |
| 视频 | 首帧视频、分镜脚本、爆款复刻脚本 | 视频创作或独立爆款复刻 |

导航、页面标题和保存反馈统一称「模板中心」，创作区入口统一称「选择模板」，保存入口保持「存为模板」。

## 分类与编辑

模板新增可选 `category: post | image | video`，与既有执行子类型 `kind` 分开。新建时明确选择分类，再选择对应类型；图文提供逐页编排，图片保留单图创作要求，视频提供整片脚本和结构化镜头。改变分类若会隐藏已有页面或视频脚本则禁用，避免丢失内容。

图文卡片在有多个图片示例时横排预览前三个示例，并显示页序摘要；示例仅展示效果，不自动当作生成输入，也不保证每个示例与某页绑定。图片、视频卡片延续单封面预览。

模板选择器同时按当前入口的分类与子类型过滤。图文模板直接进入对应商品的图文草稿，不将整组页要求塞进单图提示词。图片模板从中心选择独立图片技能；在产品编辑内也可就地选择兼容图片模板。视频保留首帧／脚本与爆款复刻的原有分流。

## 历史兼容

旧版本未保存分类时：视频子类型归入视频；非视频且有逐页内容归入图文；其余归入图片。分类在读取时推断，不修改旧版本或已接单快照。用户可编辑并保存新版本来明确调整分类。

商品图、效果示例和创作参考继续分别管理。选择模板只填入草稿；原有模型兼容、报价失效、余额校验和主动生成流程继续生效，不增加隐含 AI 调用。

## 验收

- 全量自动化测试：18 个文件、171 项通过，新增三分类过滤、旧版本读取、历史不变、分类冲突与禁止图文误入单图入口的验证。
- 生产构建通过；现有主包体积提示仍存在。
- 最终复核统一图文筛选与选择器中的「创意图文／逐图复刻」名称；新增输入若包含逐页内容，分类必须为图文，视频误带页面的回归断言已通过。修正后专项 11 项测试和生产构建通过。
- 浏览器在隔离数据下验证图片模板新建保存、图文／图片／视频筛选、旧地址跳转、图文模板导航、变量填入、两页编排及当前商品图保留、创作区兼容过滤。
- 1280／1440／1920 桌面截图位于 `.impeccable/review/template-center/`；检查无横向溢出。控制台无错误。
- 隔离环境阻止供应商调用，验收数据未写入正式数据库。示例图片沿用历史生成文件，非本轮新生成，也不代表测试商品标题对应的真实产品。
- 本轮仅升级分类与使用流程，没有接入美图设计室接口、导入其模板素材或预置验收模板到正式库。
