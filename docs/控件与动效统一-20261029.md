# 控件与动效统一

2026-10-29。依据ui-ux-pro-max与Impeccable：当前问题是悬停自动弹层、照片旋转、按钮变亮/阴影/缩放并行，下拉与Popover又缺少实际动画，造成运动层级失衡。

保留现有桌面配色、字体、Lucide图标、shadcn/Radix自定义控件。ui-ux-pro-max设计系统查询的配色/字体/营销页骨架不适合既有工作台，未覆盖已确定规范；采用其一致节奏、清晰状态、可中断和减少动态效果原则。

## 动效意图

- 重点：用户主动展开创作框与素材面板时保持空间关系。
- 连续性：创作框以320ms网格轨道收放，内容淡出，折叠内容inert且不可键盘进入；不靠卸载所有控件造成闪切。
- 反馈：颜色/边框180ms；下拉/Popover进入240ms、退出160ms，4px方向位移、轻微缩放，统一减速曲线；Tooltip延迟450ms并仅淡入淡出。
- 预算：不新增动画依赖，不做整页编排；照片不再悬停旋转，按钮不再缩放或放大阴影，卡片不再悬停抬升。折叠网格有布局成本，仅作用于底部输入区，既有ResizeObserver同步内容避让，不承诺GPU独立动画。

## 修改

顶部余额内刷新移除，仅保留一个“刷新任务与余额”图标，同步工作台、分析状态和账户查询；保留自动刷新。创作框只显示箭头图标，配Tooltip、aria-label和expanded状态。

商品/参考图从悬停自动打开改为点击展开，支持键盘与Escape；上传过程保留忙碌指示，新素材淡入。下拉箭头随打开状态转向，所有Select/Popover共享时长和方向规则。保留减少动态效果媒体查询，不使用未经用户要求的系统下拉。
