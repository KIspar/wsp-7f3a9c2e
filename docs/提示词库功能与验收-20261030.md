# 提示词库：功能与验收

更新日期：2026-10-30。入口：左侧「工作台管理 → 提示词库」，路径 `/prompt-library`。

## 使用流程

1. 手动新建模板，或从真实生成结果、内容作品、爆款复刻分镜点击「存为模板」。保存前可编辑原文、改为变量、选择效果示例和参考素材。
2. 在提示词库按图片／视频、类型、标签和关键词检索，打开详情查看效果、逐页要求、脚本与历史版本。
3. 选择独立创作技能或已有商品，进入对应创作区。也可直接在创作栏点击「选用模板」。
4. 填写 `{{商品名称}}`、`{{场景}}` 等变量，选择追加或替换要求，明确选择是否带入参考和兼容参数，再点击「带入草稿」。
5. 核对草稿后，仍通过原有报价、余额检查和生成流程提交。保存、选用和导出模板不调用付费模型。

## 模板分类

| 类型 | 保存的内容 | 主要用途 |
| --- | --- | --- |
| 图片创作 | 通用要求、逐页编排 | 独立图片技能、商品创意图文 |
| 图片逐图复刻 | 替换对象、逐页要求、同行参考 | 一键对标、商品逐图复刻 |
| 首帧视频 | 动作、场景和镜头要求 | 视频生成、商品视频创作 |
| 分镜脚本 | 整片脚本、有顺序的结构化镜头 | 视频创作、爆款复刻分镜参考 |
| 爆款复刻 | 替换要求、分镜、首帧与视频提示词 | 商品工坊独立爆款复刻工作区 |

结构化镜头包含名称、建议时长、场景、人物造型、商品替换、动作、运镜、台词、首帧重绘要求和视频提示词；最多 20 个镜头。图片编排最多 20 页，仍受具体生成入口的批次上限约束。

## 素材与应用边界

- **效果示例**最多 8 个，可为图片或视频，只供预览，不会自动发送到生成模型。
- **创作参考**最多 20 个，选用时默认不带入；勾选后仅进入兼容的参考角色。
- **商品图片**由当前商品／创作区提供。模板不自动替换商品图和商品资料。
- 变量在选用时替换。旧结果中的具体商品名称、材质和卖点不会被自动识别清除，保存和应用界面均提示人工核对。
- 参数默认沿用当前草稿。主动带入时验证模型、比例、时长和参数能力；不兼容则明确拦截，不自动换模型。
- 普通视频入口不把模板参考图片／视频冒充首帧商品图；参考可查看，输入素材需按当前入口重新选择。
- 爆款复刻可保存分镜方法，但原片时间轴仍来自本地拆解。模板镜头需手动填入当前镜头，不自动重写原片切点，也不自动启动拆解、分析或生成。
- 模板只保留创作要求、编排和相关参数；内容作品的发布标题、正文仍由对应作品独立管理。

## 版本、草稿和历史

编辑模板生成不可变新版本，旧任务引用的版本继续存在。详情可选历史版本；从提示词库跳转创作时保留选中的确切版本。

新建保存使用幂等凭据；模板修改与归档使用修订检查，防止旧编辑覆盖新内容。归档可恢复，归档模板不能继续选用。编辑器未提交内容暂存在本机，关闭时说明暂存行为。

应用默认追加，也可明确替换要求与编排；保留当前商品素材。模板来源及版本随草稿保存，并进入生成任务快照。修改草稿使现有报价失效，仍需重新报价。

## 接口与存储

沿用 Fastify、SQLite 文档存储和现有素材库，不新增付费执行队列。

| 接口 | 职责 |
| --- | --- |
| `GET /api/prompt-templates` | 分类、关键词、标签、兼容类型、归档状态与分页查询（每页 20 条） |
| `POST /api/prompt-templates/capture` | 从真实结果、作品或分镜生成待编辑模板 |
| `POST /api/prompt-templates` | 幂等创建模板 |
| `GET /api/prompt-templates/:id` | 模板、全部版本及相关素材 |
| `PUT /api/prompt-templates/:id` | 按修订创建新版本 |
| `PATCH /api/prompt-templates/:id` | 按修订归档／恢复 |
| `POST /api/prompt-templates/:id/render` | 校验确定版本与变量，生成待应用内容 |

文档类型：`prompt-template`、`prompt-version`、`prompt-save`。媒体引用沿用 `asset`，不复制文件，不保存供应商凭据。不能将模拟生成记录和原型素材存为真实效果示例。

全量 `npm test`：18 个文件、170 项测试通过。`npm run build`：TypeScript、Vite 前端和 Node 后端构建通过；现有主包体积提示仍存在。
