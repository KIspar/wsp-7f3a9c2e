# 商品资料独立于技能草稿，采用关系独立于生成尝试

2026-10-29，已采用。为支持一款商品连续产出成套图，将商品原图、名称与已确认参数存为独立资料，由用户明确载入技能草稿；提交时保存资料修订与输入快照。选择显式复制而非所有技能实时引用同一份输入，是为保留各技能独立要求、接单成功重置约定，以及历史任务不随资料更新而改变的边界。

每个创作条目的采用版本单独持久化，关联具体生成尝试；不把“最新成功图”视为自动采用，也不改写原尝试。合集导出固定素材和版本清单，产物文件不可变，避免新生成或改选让历史下载悄悄变化。代价是资料更新需主动重新载入，生成新版本后也需主动采用；两者均优先于隐式覆盖用户决定。
