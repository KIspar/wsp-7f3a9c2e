# 商品工坊推广制作：任务工作台与作品复刻方案

更新：2026-10-29。适用于商品工坊「推广制作」，不改变产品编辑的手机详情模拟器。

## 1. 产品目标

围绕一款商品连续生产多条推广内容，并将有效内容保留为可追溯、可复刻的作品。

流程：**准备创意 → 查询报价 → 确认真实生成 → 查看候选 → 确认作品版本 → 下载使用 → 人工记录表现 → 复刻新作品。**

| 概念 | 职责 |
| --- | --- |
| 任务 | 一次已接单的生成请求，保留输入、模型、状态、费用和结果 |
| 作品 | 一组有顺序的图文或一条完整视频，拥有多个候选／确认版本 |
| 版本 | 独立保存标题、正文、脚本、页序、媒体选择和生成关联 |
| 效果记录 | 绑定确定版本和一次发布，按记录时间追加的人工数据 |

不把推广内容继续放进商品级的一组「采用位置」。商品详情保留「采用素材」；推广制作使用「确认作品版本」。

## 2. 工作台布局

推广制作占满内容宽度，取消常驻商品手机预览。产品编辑仍保留该预览。

```text
商品信息、来源、任务、下载
产品编辑 / 推广制作
┌─────────────────────────────────┬─────────────────────────┐
│ 类型、状态、搜索                │ 图文 / 视频 · 保存 · 收起│
│                                 ├─────────────────────────┤
│ 作品任务列表                    │ 独立创作表单            │
│ 名称、时间、进度、确认状态      │ 商品图、同行参考        │
│ 整组图片 / 视频封面             │ 要求、内容编排          │
│ 预览、下载、复刻                │ 模型及参数              │
│                                 ├─────────────────────────┤
│ 独立滚动                        │ 固定报价与生成入口      │
└─────────────────────────────────┴─────────────────────────┘
```

列表筛选不控制右侧创作类型。例如查看视频任务时，可以准备下一组图文。左右两栏独立滚动，右侧操作区固定，不遮挡表单。侧栏在 1280／1440／1920px 下分别约 380／400／440px；收起为 56px 图标栏，展开后恢复草稿。

每页 20 个作品，按作品创建时间倒序；同一作品的新候选在版本选择器内查看，不追加成无关联作品。任务状态原位更新。后台出现新作品时提示点击查看，不自动顶走当前浏览位置。主动提交后显示新作品。

作品点击后使用约 440px 的覆盖式侧边抽屉，不挤压任务区和创作区。图片打开固定尺寸素材预览，支持原有滚轮缩放、拖拽；视频使用自定义播放器。列表视频不自动播放。

## 3. 图文与视频分别设计右侧创作表单

两类创作使用不同输入块，复用相同侧栏外壳与保存、报价流程。

### 图文：参考一键对标

按「商品图片 → 同行图组 → 图文要求 → 逐页编排 → 生成设置」组织。

- 商品图决定商品外观；同行图参考场景、人物与构图，两者明确分区。
- 同行图组最多 20 张，并受系统批次上限约束。每张同行图对应一页，所选顺序即页序，页数随图组变化，不能另填冲突数量。
- 每页只发送选中的商品图与该页对应同行图，不把整组同行图重复发送到每页。保留素材与页要求快照，后端检查完整映射、素材真实性和模型引用上限。
- 不选择同行图时，可按图文页数与逐页要求自由创作。
- 旧草稿的整组通用参考仍可读取，标注「通用参考」；重新选择图组才切换为逐页对标，不能静默改变历史含义。
- 图文要求旁使用 AI 润色小图标，点击即提交文字润色，不再打开确认弹窗；显示处理中，完成直接回填，并可撤销。若用户期间修改原文，则保留新输入，提供复制候选结果。同行图片来源链接仅记录来源，不自动采集。
- 标题、正文和逐页内容在编排面板编辑，单独属于这篇作品。
- 模型、比例、页数以及分辨率、版本、质量、背景、语言、多图差异等参数直接显示在侧栏，使用现有中文自定义控件；不再打开图片参数弹窗。主操作「制作图文 · 查询报价」。

### 视频：生成与反推结合

侧栏提供「直接生成／参考视频复刻」两条路径，保留共同的商品图片、视频创意、可编辑脚本和生成设置。

**直接生成：**选择商品图片，填写开场、动作、场景、运镜或脚本，查询报价并确认真实生成。

**参考视频复刻：**选择单个 MP4／WebM → 点击「反推镜头与提示词」→ 确认开始 GEM 原生视频分析 → 检查候选 → 主动采纳到脚本 → 按目标商品改写 → 查询生成报价 → 确认生成。

- 参考视频延续 30MB、120 秒限制，后台校验格式与时长。
- 打开面板、切换路径或上传素材均不自动调用分析／生成。取消、失败保留脚本；迟到结果通过现有分析面板确认，不直接覆盖新输入。
- 同行视频只用于主动反推，不作为未验证支持视频输入的生成模型附件。生成使用商品图片及用户确认的脚本。
- 模型、比例、真实可选时长和专用参数独立于图文。一次接单生成一条完整视频。
- 反推与成片生成分别计费，页面分别展示分析与生成入口。

两类草稿在商品下独立保存，切换、刷新后恢复；侧栏内长内容滚动，报价按钮固定在底部。收起后表单与底部按钮退出焦点和可访问树，图标可重新展开。

### 接单与连续生产

成功接单与作品／版本关联、草稿清理在同一数据库事务完成。

保留：当前商品、选中商品图、模型、合法常用参数、图文页数。

清空：本次创作要求、同行参考图／视频、同行文案、标题正文、脚本、逐页内容、复刻关联；新建输出位置标识。

无需等待上一条任务完成即可准备下一条。报价失败、提交失败或结果待核实时保留完整草稿。接单未知只查询原幂等请求，不自动重新提交付费调用。

## 4. 作品与版本

### 生成候选

现有 Batch／Attempt 承担真实执行，不新增第二套付费队列。每次接单关联 PromotionWork 和 PromotionVersion，版本保存本次输入快照与批次。

图文按组保存，每页保持独立输出位置。部分失败保留成功页，可只报价并补做失败页。

### 确认与修订

预览内选择候选、调整页序、编辑标题正文后确认整组。缺页可下载已有素材，但不能确认完整作品。

确认操作创建不可变新版本，并更新作品的当前确认版本。只改文字或页序复用已保存媒体，不调用付费接口。历史效果记录、下载文件仍指向原版本。

重新生成只为当前作品增加候选版本；原确认版本保持有效。跨作品和跨页结果不能混用，模拟和缺失素材不能确认。

## 5. 值得复刻与效果记录

「值得复刻」绑定用户选定的已确认版本。跨商品筛选可以找到有效来源。

效果记录为人工输入，不接抖音账号、不自动拉数：

| 字段 | 规则 |
| --- | --- |
| 发布记录 | 同一版本可有多次发布；同一次发布的数据按时间追加 |
| 发布链接、发布时间 | 可选；链接使用 HTTP(S) |
| 数据记录时间 | 保存本次记录的时间 |
| 播放／曝光、点赞、评论、收藏、分享 | 可选非负整数 |
| 成交订单数、成交金额 | 可选，金额允许小数 |
| 备注 | 保存主观观察，不计算综合得分 |

空值显示「未填写」，实际零值显示 0。不同记录不互相覆盖，不跨时间或账号自动判断「爆款」。

## 6. 复刻与重新生成

复刻从确定版本开始，先选择目标商品、来源版本并检查继承信息，只载入草稿，不立即收费。

| 操作 | 处理 |
| --- | --- |
| 同款复刻 | 保留内容结构、脚本、商品图及可用模型参数，新建独立作品 |
| 跨商品复刻 | 替换为目标商品图与资料；清除来源事实；保留来源结构供人工改写 |
| 重新生成 | 同一作品、同一商品、相同输出位置，新建候选版本 |

跨商品不能可靠地仅靠字符串替换清除源文案中的所有商品事实。因此采用保守方式：保留来源内容结构为**只读参考**，该内容不自动进入生成提示词；目标页要求与脚本骨架使用中性结构，用户按目标商品改写后再报价。不得将来源名称、卖点、材质、承诺当成目标商品事实。

视频复刻沿用脚本框架，不默认发送来源 MP4。需重新分析时，用户主动使用视频反推。

目标已有未提交草稿时明确选择替换或取消，替换前备份旧稿。来源作品、来源确定版本和直接衍生作品保持可查。新作品的表现不回写来源。

失效模型和不支持的参数明确拦截，不自动换模型。

## 7. 数据与接口

新增实体使用现有 SQLite documents 存储：

| 实体 | 保存内容 |
| --- | --- |
| PromotionWork | 商品、类型、名称、创建时间、修订、确认版本和复刻来源 |
| PromotionVersion | 作品文案、脚本、页序、输入快照、批次、选中尝试和媒体 |
| PromotionDraft | 商品下图文／视频的独立可恢复草稿 |
| PromotionPerformanceRecord | 确定版本、发布记录、时间、人工指标和备注 |

CreativeContext 兼容增加 promotionWorkId、promotionVersionId。报价哈希和提交幂等指纹覆盖该上下文。接单验证当前商品、草稿修订和完整输入快照。

| 接口 | 用途 |
| --- | --- |
| GET /api/catalog/products/:id/promotions | 分页筛选作品；worthy＋cross 支持跨商品来源 |
| GET /api/promotions/:id | 作品、候选／确定版本、任务、效果和直接衍生 |
| GET/PUT /api/catalog/products/:id/promotion-drafts/:type | 读取／按修订保存独立草稿 |
| POST /api/catalog/products/:id/promotion-drafts/:type/plan | 使用当前保存快照查询真实报价 |
| POST /api/submit | 复用原接单服务，原子写入作品关联并清理已消费草稿 |
| POST /api/promotions/:id/confirm | 幂等确认版本或创建文字／页序修订 |
| POST /api/promotions/:id/replicate | 同款／跨商品复刻或载入重新生成草稿 |
| PUT /api/promotions/:id/worthy | 标记指定确定版本 |
| POST /api/promotions/:id/performance | 追加人工表现记录 |
| POST /api/promotions/:id/export | 固定版本导出 |

## 8. 迁移与导出

迁移按旧商品推广批次建立历史作品，同批图文页成组，不混合不同批次。仅用该批已有采用关系恢复确定媒体。缺失历史文案标为「历史文案未保存」；商品当前旧文案保留在未确认草稿，不冒充旧任务快照。

迁移 ID 由旧批次确定，可重复运行且不产生重复作品，不调用付费接口。

单作品下载按固定版本生成：

- 图文：页序编号图片、标题正文／提示词 Markdown、版本清单。
- 视频：原始 MP4、标题正文／脚本 Markdown、版本清单。
- 未完整候选：只包含可用媒体，清单标记缺页及 complete=false。
- 商品整包：可选择多个作品确定版本，按作品名称／版本分目录，不再混成一组推广图片。

后续编辑不能修改历史已生成下载包。

## 9. 视觉与动效

使用系统既有中文字体、shadcn/ui 自定义组件和 Tailwind 语义变量。所有产品参数标签中文显示，不使用系统原生下拉。

任务与缩略图原位更新，视频封面不循环播放。悬停只改变颜色／边框，不抬升任务卡。下拉延续 240ms、面板延续 320ms 的全局令牌，支持减少动态效果。抽屉为覆盖式，打开不改变输入栏和任务卡的宽度。

## 10. 验收

自动化覆盖：逐图对标输入映射、缺失与不匹配素材拦截、视频脚本进入生成但参考 MP4 不进入生成、明确会话失效恢复且不重发未知付费请求、原子接单、幂等回放、连续提交、草稿隔离、重启恢复、单页补做、不可变确认版本、跨作品／页结果拦截、同款与跨商品复刻、迁移重复执行、人工指标 null／0、确定版本及整包导出。

浏览器覆盖：1280／1440／1920 桌面宽度，任务列表、不同的图文／视频输入区、展开收起、覆盖抽屉、自定义下拉互斥、键盘焦点与固定媒体预览。

真实执行复用已验收图片／视频 worker、报价、余额检查、供应商任务状态、费用与退款服务。界面及迁移验收复用此前真实生成素材；不创建模拟成品，不为验证页面重复付费。

首版范围：不接账号、不发布／投放、不自动判断爆款、不建设复杂数据看板。先完成任务持续生产、作品完整保存、有效确定版本可复刻的闭环。

2026-10-29 交互补充：所有 AI 润色入口统一为点击直接执行，仅发送待润色文字；提炼卖点、图片／视频反推仍保留素材与结果面板。失败、空结果、超长结果或期间的新输入均不覆盖原文，提交未知只核实原幂等请求，不自动重新收费。
