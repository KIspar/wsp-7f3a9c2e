## 使用

打开「模板中心 → 图文」，按「服装」或「鞋包配饰」标签筛选。查看示例后选择已有商品，填入商品名称并带入图文创意草稿；各页要求可继续修改。默认比例 3:4，不指定模型，不自动调用分析或生成接口。
