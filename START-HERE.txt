Workspace — 使用说明

一、开始使用
完整解压下载包到固定文件夹，不要在压缩包内直接运行。
Windows x64：双击 Windows-启动.bat（也可以双击 run.bat）。
Mac（Intel / Apple Silicon）：双击 Mac-启动.command（也可以双击 Start.command）。
程序会自动准备本机运行环境并打开浏览器，不需要手动安装 Node.js，也不用输入命令。
首次准备需要联网，下载来自 GitHub；正常再次启动直接复用本机环境。
使用时保留启动窗口；需要停止时在启动窗口按 Ctrl+C。

二、安装或修复环境
Windows：双击 Windows-安装环境.bat 或 Windows-修复环境.bat。
Mac：双击 Mac-安装环境.command 或 Mac-修复环境.command。
修复前先关闭工作台。修复只处理运行环境和程序依赖，不清空 data 文件夹中的作品、配置或 API 密钥。
下载中断或校验失败时会停止安装，可以重新双击修复入口重试。
环境下载与依赖安装不需要 GitHub 登录，也不需要管理员权限。

三、Mac 文件打不开
下载包保留了启动文件的执行权限。如权限丢失，可使用 Mac-修复权限.command。
如 macOS 提示来源确认，请右键文件选择“打开”，按系统提示确认，不需要输入终端命令。
安装环境、修复环境同时提供 .sh 文件，供需要时使用；普通用户使用 .command 即可。

四、本机数据
首次打开后在模型配置中填写自己的 API Key。数据和凭据保存在本机 data/。
版本页面支持检查和安装 GitHub 新版本。
旧版如果没有这些入口，请重新下载新版 ZIP 到新文件夹。迁移前先停止旧程序并单独备份 data/，不要让两个程序共用一份数据。
本安装器准备工作台核心运行环境。可选本地视频工具的状态请在工作台帮助页查看。
